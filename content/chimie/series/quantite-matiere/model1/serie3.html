Exercices 7 à 8 : Dilution - Solutions aqueuses - Protocole expérimental

7 Solution d'éthanol à 95%

Une solution aqueuse \(S_1\) d'éthanol à \(95\%\) en volume contient \(95\text{ mL}\) d'éthanol de formule \(\text{C}_2\text{H}_6\text{O}\) dans un volume de \(100\text{ mL}\) de solution. La densité de l'éthanol pur est \(d = 0,79\).

Données : \(\rho_{eau} = 1,00\text{ g/mL}\), \(M_C = 12\text{ g/mol}\), \(M_H = 1\text{ g/mol}\), \(M_O = 16\text{ g/mol}\)
1)

Calculer la masse d'éthanol dans \(100\text{ mL}\) de solution \(S_1\).

✅ Solution
On a, la masse volumique de l'éthanol : \(\rho = d \times \rho_{eau} = 0,79 \times 1,00 = 0,79\text{ g/mL}\)
Or, le volume d'éthanol dans 100 mL de $S_1$ vaut : \(V = 95\text{ mL}\)
D'où :
$$m = \rho \times V = 0,79 \times 95 = 75,1\text{ g}$$

Conclusion : \(m = 75,1\text{ g}\)

2)

Quelle est la concentration molaire \(C_1\) de l'éthanol dans cette solution ?

✅ Solution
On a, la masse molaire de l'éthanol :
$$M = 2 \times 12 + 6 \times 1 + 16 = 24 + 6 + 16 = 46\text{ g/mol}$$
D'où, la quantité de matière :
$$n = \frac{m}{M} = \frac{75,1}{46} = 1,63\text{ mol}$$
Alors, la concentration molaire :
$$C_1 = \frac{n}{V} = \frac{1,63}{0,100} = 16,3\text{ mol/L}$$

Conclusion : \(C_1 = 16,3\text{ mol/L}\)

3a)

On souhaite préparer un volume \(V_2 = 100\text{ mL}\) de solution \(S_2\) à \(70\%\). Calculer le volume \(V_1\) de solution \(S_1\) à prélever.

✅ Solution
On a, le volume d'éthanol dans $S_2$ : \(V_{éthanol} = 70\text{ mL}\)
Or, l'éthanol provient de $S_1$, donc le volume d'éthanol est conservé :
$$V_1 \times 0,95 = 70 \iff V_1 = \frac{70}{0,95} = 73,7\text{ mL}$$

Conclusion : \(V_1 = 73,7\text{ mL}\)

3b)

Décrire le mode opératoire de cette préparation en choisissant le matériel nécessaire.

✅ Solution

Matériel nécessaire :

  • Solution mère \(S_1\)
  • Eau distillée
  • Fiole jaugée de 100 mL
  • Pipette jaugée de 73,7 mL (ou éprouvette graduée)
  • Propipette
  • Becher

Protocole :

On a : à l'aide d'une pipette jaugée, prélever \(73,7\text{ mL}\) de la solution \(S_1\).
Ensuite : introduire le prélèvement dans une fiole jaugée de \(100\text{ mL}\).
Puis : ajouter de l'eau distillée jusqu'au trait de jauge.
Enfin : homogénéiser par retournement.

Conclusion : On obtient \(100\text{ mL}\) de solution à \(70\%\).

8 Acide éthanoïque

Une solution \(S_0\) d'acide éthanoïque \(\text{C}_2\text{H}_4\text{O}_2\) a une densité par rapport à l'eau \(d = 1,05\). Le pourcentage massique en acide éthanoïque vaut \(p = 90,0\%\).

Données : \(\rho_{eau} = 1,00\text{ g/mL}\), \(M_C = 12\text{ g/mol}\), \(M_H = 1\text{ g/mol}\), \(M_O = 16\text{ g/mol}\)
1)

Calculer la concentration molaire \(C_0\) de l'acide éthanoïque dans cette solution.

✅ Solution détaillée
On a, la masse molaire de l'acide éthanoïque :
$$M = 2 \times 12 + 4 \times 1 + 2 \times 16 = 24 + 4 + 32 = 60\text{ g/mol}$$
Or, la masse volumique de la solution : \(\rho = d \times \rho_{eau} = 1,05 \times 1,00 = 1,05\text{ g/mL} = 1050\text{ g/L}\)
D'où, la masse d'acide dans 1 L :
$$m = \rho \times V \times p = 1050 \times 1 \times 0,900 = 945\text{ g}$$
Alors, la concentration molaire :
$$C_0 = \frac{n}{V} = \frac{m}{M \times V} = \frac{945}{60 \times 1} = 15,8\text{ mol/L}$$

Conclusion : \(C_0 = 15,8\text{ mol/L}\)

2)

On dilue cette solution \(200\) fois de façon à obtenir un volume \(V = 100\text{ mL}\) de solution diluée. Décrire avec précision le protocole expérimental en indiquant les précautions à prendre sachant que la solution \(S_0\) est corrosive.

✅ Solution

Matériel nécessaire :

  • Solution mère \(S_0\) (corrosive)
  • Eau distillée
  • Fiole jaugée de 100 mL
  • Pipette jaugée de 0,5 mL
  • Propipette
  • Becher
  • Gants de protection
  • Lunettes de sécurité
  • Hotte aspirante

Calcul : \(V_0 = \dfrac{V}{200} = \dfrac{100}{200} = 0,5\text{ mL}\)

Protocole :

On a : ⚠️ Porter des gants et des lunettes de protection. Travailler sous hotte aspirante.
Ensuite : prélever \(0,5\text{ mL}\) de la solution \(S_0\) à l'aide d'une pipette jaugée.
Puis : introduire le prélèvement dans une fiole jaugée de \(100\text{ mL}\).
Ensuite : rincer la pipette avec de l'eau distillée et ajouter dans la fiole.
Puis : compléter avec de l'eau distillée jusqu'au trait de jauge.
Enfin : homogénéiser par retournement.

Conclusion : On obtient \(100\text{ mL}\) de solution diluée \(200\) fois.

3)

Quel volume de solution \(S_0\) faut-il prélever pour obtenir une solution de degré d'acidité égale à \(7,0\) (masse d'acide en gramme dans \(100\text{ g}\) de solution) de volume \(V' = 1,0\text{ L}\) et de masse volumique \(\rho' = 1,01\text{ g/mL}\) ?

✅ Solution
On a, le volume occupé par $100\text{ g}$ de solution :
$$V_{100g} = \frac{100}{\rho'} = \frac{100}{1,01} = 99,0\text{ mL}$$
D'où, pour 1 L, le degré d'acidité est :
$$\text{Degré} = 7,0 \times \frac{1000}{99,0} = 70,7$$
Donc, la masse d'acide dans 1 L :
$$m = 70,7\text{ g}$$
Or, en notant $V_0$ le volume de $S_0$ prélevé, la masse d'acide qu'il apporte est :
$$m_0 = \rho \times V_0 \times 0,900 = 1050 \times V_0 \times 0,900$$
D'où, en identifiant les deux masses :
$$70,7 = 1050 \times V_0 \times 0,900 \iff V_0 = \frac{70,7}{945} = 0,0748\text{ L} = 74,8\text{ mL}$$

Conclusion : \(V_0 = 74,8\text{ mL}\)
