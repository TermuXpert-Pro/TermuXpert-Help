Exercice 2

Densité de l'éthanol - Mélange avec l'heptane Niveau : Facile

1 Énoncé

L'éthanol est un solvant. Pour déterminer sa densité, on verse \(50\text{ mL}\) d'éthanol dans une éprouvette graduée que l'on pèse sur une balance de précision : la masse mesurée est \(m = 94,3\text{ g}\). L'éprouvette vide a une masse \(m' = 53,8\text{ g}\).

Donnée : \(\rho_{eau} = 1,00\text{ g/mL}\)
1)

Calculer la masse d'éthanol contenu dans l'éprouvette.

✅ Solution
Étape 1 : La masse d'éthanol est la différence entre la masse de l'éprouvette pleine et la masse de l'éprouvette vide :
$$m_{\text{éthanol}} = m - m'$$
Étape 2 : Application numérique :
$$m_{\text{éthanol}} = 94,3 - 53,8 = 40,5\text{ g}$$
Résultat
$$m_{\text{éthanol}} = 40,5\text{ g}$$
2)

Calculer la densité de l'éthanol.

✅ Solution
Étape 1 : À volume égal (\(50\text{ mL}\)), la masse d'eau est :
$$m_{eau} = \rho_{eau} \times V = 1,00 \times 50 = 50,0\text{ g}$$
Étape 2 : La densité est le rapport des masses à volume égal :
$$d_{\text{éthanol}} = \frac{m_{\text{éthanol}}}{m_{eau}}$$
Étape 3 : Application numérique :
$$d_{\text{éthanol}} = \frac{40,5}{50,0} = 0,81$$
Résultat
$$d_{\text{éthanol}} = 0,81$$

L'éthanol est moins dense que l'eau (\(d < 1\)).

Formule à retenir
$$d = \frac{m_{\text{corps}}}{m_{\text{eau}}} \quad (\text{à volume égal})$$
3)

On mélange \(50\text{ mL}\) d'heptane avec \(20\text{ mL}\) d'éthanol. On verse dans une ampoule à décanter. Il se forme deux phases. Commenter et schématiser l'ampoule.

Donnée : Densité de l'heptane \(d = 0,68\)
✅ Solution
Étape 1 : Comparaison des densités :
$$d_{\text{heptane}} = 0,68 \quad ; \quad d_{\text{éthanol}} = 0,81$$

\(d_{\text{heptane}} < d_{\text{éthanol}}\)

Étape 2 : Le liquide le moins dense se place au-dessus.
Donc l'heptane (\(d = 0,68\)) surmonte l'éthanol (\(d = 0,81\)).

Ampoule à décanter - Heptane (haut) / Éthanol (bas)

Conclusion
  • Phase supérieure : Heptane (\(d = 0,68\))
  • Phase inférieure : Éthanol (\(d = 0,81\))

Les deux liquides sont non miscibles.
