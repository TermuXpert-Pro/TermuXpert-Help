Exercice 6

Récepteur thermique - Courant alternatif Niveau : Moyen

1 Énoncé

Un récepteur thermique est branché en alternatif sous une tension efficace de \(220\text{ V}\). Sa puissance est de \(1100\text{ W}\).

1. Calculer l'intensité efficace \(I\) qui traverse le récepteur.

2. Calculer la résistance \(R\) du récepteur.

3. Calculer l'intensité maximale du courant alternatif traversant ce récepteur.

4. Ce courant a une période de \(20\text{ ms}\). Calculer sa fréquence.

5. Calculer l'énergie consommée pendant \(30\text{ minutes}\) de fonctionnement. Exprimer le résultat en \(\text{Wh}\).

Récepteur thermique - Courant alternatif

1.

Calculer l'intensité efficace \(I\).

✅ Solution
Rappel :
$$P = U \times I \quad \Rightarrow \quad I = \frac{P}{U}$$
Application numérique :
$$I = \frac{1100}{220} = 5,0\text{ A}$$
Réponse
$$I = 5,0\text{ A}$$
2.

Calculer la résistance \(R\).

✅ Solution
Rappel :
$$R = \frac{U}{I}$$
Application numérique :
$$R = \frac{220}{5,0} = 44\ \Omega$$
Réponse
$$R = 44\ \Omega$$
3.

Calculer l'intensité maximale \(I_{max}\).

✅ Solution
Rappel :
$$I_{max} = I \times \sqrt{2}$$
Application numérique :
$$I_{max} = 5,0 \times \sqrt{2} \approx 7,07\text{ A}$$
Réponse
$$I_{max} \approx 7,07\text{ A}$$
4.

Calculer la fréquence \(f\).

✅ Solution
Rappel :
$$f = \frac{1}{T}$$
Conversion :
$$T = 20\text{ ms} = 20 \times 10^{-3} = 0,020\text{ s}$$
Application numérique :
$$f = \frac{1}{0,020} = 50\text{ Hz}$$
Réponse
$$f = 50\text{ Hz}$$
5.

Calculer l'énergie consommée en \(\text{Wh}\).

✅ Solution
Rappel :
$$E = P \times \Delta t$$
Conversion :
$$\Delta t = 30\text{ min} = 0,5\text{ h}$$
Application numérique :
$$E = 1100 \times 0,5 = 550\text{ Wh}$$
Réponse
$$E = 550\text{ Wh} = 0,55\text{ kWh}$$
