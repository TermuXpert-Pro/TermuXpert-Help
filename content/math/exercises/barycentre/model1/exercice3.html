Exercice 3

Coordonnées - Ensemble de points (Cercle) Niveau : Moyen

1 Énoncé

Dans le plan $(P)$ rapporté à un repère orthonormé $(O; \vec{i}; \vec{j})$.

Soient $A(0; 5)$ et $B(3; 2)$ deux points du plan.

Soit $G = \text{Bar}\{(A, 1); (B, 2)\}$.

1)

Déterminer les coordonnées du point $G$.

✅ Solution détaillée

Rappel : Si $G = \text{Bar}\{(A, \alpha); (B, \beta)\}$ alors :

$$x_G = \frac{\alpha x_A + \beta x_B}{\alpha + \beta} \quad \text{et} \quad y_G = \frac{\alpha y_A + \beta y_B}{\alpha + \beta}$$
Étape 1 : On identifie les poids :
$\alpha = 1$ et $\beta = 2$
Étape 2 : On calcule la somme des poids :
$\alpha + \beta = 1 + 2 = 3 \neq 0$ ✅
Étape 3 : On calcule l'abscisse $x_G$ :
$$x_G = \frac{1 \times 0 + 2 \times 3}{1 + 2} = \frac{0 + 6}{3} = 2$$
Étape 4 : On calcule l'ordonnée $y_G$ :
$$y_G = \frac{1 \times 5 + 2 \times 2}{1 + 2} = \frac{5 + 4}{3} = 3$$
Conclusion

Les coordonnées de $G$ sont :

$$G(2; 3)$$
2)

Déterminer et dessiner l'ensemble suivant :

$$(C) = \left\{ M \in (P) \mid \| \overrightarrow{MA} + 2\overrightarrow{MB} \| = 6 \right\}$$
✅ Solution détaillée

Rappel : Propriété caractéristique du barycentre :

$$\overrightarrow{MA} + 2\overrightarrow{MB} = 3\overrightarrow{MG}$$
Étape 1 : On applique la propriété caractéristique :
$$\overrightarrow{MA} + 2\overrightarrow{MB} = 3\overrightarrow{MG}$$
Étape 2 : L'équation devient :
$$\|3\overrightarrow{MG}\| = 6$$
Étape 3 : On simplifie :
$$3 \| \overrightarrow{MG} \| = 6 \iff \| \overrightarrow{MG} \| = 2$$
Étape 4 : Cela signifie que la distance $MG = 2$.
Conclusion

L'ensemble $(C)$ est le cercle de centre $G(2; 3)$ et de rayon $r = 2$ cm.

$$(C) = \mathcal{C}(G, 2)$$

Cercle $\mathcal{C}(G, 2)$ de centre G(2;3) et de rayon r=2
