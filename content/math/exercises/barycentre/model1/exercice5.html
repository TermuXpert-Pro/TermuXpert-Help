1 Exercice 5 - Associativité

Soit $G = \text{Bar}\{(A, 2); (B, -3); (C, 5)\}$.

Utiliser la propriété d'associativité pour construire le point $G$.

1)

Construire le barycentre $G$ du système pondéré $\{(A, 2); (B, -3); (C, 5)\}$.

✅ Solution détaillée

Propriété d'associativité :

Rappel

Si $E = \text{Bar}\{(A, \alpha); (B, \beta)\}$ alors :

$$G = \text{Bar}\{(A, \alpha); (B, \beta); (C, \gamma)\} = \text{Bar}\{(E, \alpha + \beta); (C, \gamma)\}$$
Étape 1 : Soit $E = \text{Bar}\{(A, 2); (B, -3)\}$.
La somme des poids est : $2 + (-3) = -1 \neq 0$ ✅
Étape 2 : On construit le point $E$ :
$$2\overrightarrow{EA} + (-3)\overrightarrow{EB} = 0$$ $$2\overrightarrow{EA} = 3\overrightarrow{EB}$$
Étape 3 : On pose $M = A$ dans la propriété caractéristique :
$$(-1)\overrightarrow{AE} = 2\overrightarrow{AA} - 3\overrightarrow{AB} = -3\overrightarrow{AB}$$ $$\overrightarrow{AE} = 3\overrightarrow{AB}$$
Étape 4 : D'après l'associativité :
$$G = \text{Bar}\{(E, -1); (C, 5)\}$$
Étape 5 : On construit $G$ :
$$(-1)\overrightarrow{GE} + 5\overrightarrow{GC} = 0$$ $$5\overrightarrow{GC} = \overrightarrow{GE}$$
Étape 6 : On pose $M = C$ :
$$4\overrightarrow{CG} = -\overrightarrow{CE} + 5\overrightarrow{CC} = -\overrightarrow{CE}$$ $$\overrightarrow{CG} = -\frac{1}{4}\overrightarrow{CE}$$
Conclusion

$G$ est construit tel que :

  • $E$ est sur $(AB)$ avec $\overrightarrow{AE} = 3\overrightarrow{AB}$
  • $G$ est sur $(CE)$ avec $\overrightarrow{CG} = -\frac{1}{4}\overrightarrow{CE}$

Construction de G par associativité

2 Exercice 6 - Centre de gravité

Soit $ABC$ un triangle et $G$ le centre de gravité du triangle $ABC$.

Soit $I$ le milieu du segment $[BC]$.

1)

Montrer que $G$ est le barycentre du système pondéré $\{(A, 1); (I, 2)\}$.

✅ Solution détaillée
Étape 1 : Le centre de gravité $G$ du triangle $ABC$ est le barycentre de :
$$G = \text{Bar}\{(A, 1); (B, 1); (C, 1)\}$$
Étape 2 : $I$ est le milieu du segment $[BC]$, donc :
$$I = \text{Bar}\{(B, 1); (C, 1)\}$$
Étape 3 : D'après la propriété d'associativité, on peut remplacer $(B, 1)$ et $(C, 1)$ par $(I, 2)$ :
$$G = \text{Bar}\{(A, 1); (I, 2)\}$$
Étape 4 : Vérification :
$$\overrightarrow{GA} + 2\overrightarrow{GI} = 0$$
$$\overrightarrow{GA} + 2\overrightarrow{GI} = \overrightarrow{GA} + \overrightarrow{GB} + \overrightarrow{GC} = 0$$
Conclusion

$G$ est le barycentre de $\{(A, 1); (I, 2)\}$.

C'est-à-dire que $G$ est situé aux $\frac{2}{3}$ de la médiane $[AI]$.

Centre de gravité G = Bar{(A,1); (I,2)}
