1 Exercice 9 - Coordonnées

Dans le plan $(P)$ rapporté à un repère orthonormé $(O; \vec{i}; \vec{j})$.

Soient $A(-1; 1)$, $B(0; 2)$, $C(1; -1)$, $D(1; 0)$.

1)

Déterminer les coordonnées de $K = \text{Bar}\{(A, 2); (B, 3)\}$.

✅ Solution
Étape 1 : On identifie les poids : $\alpha = 2$, $\beta = 3$.
$\alpha + \beta = 5 \neq 0$ ✅
Étape 2 : On calcule $x_K$ :
$$x_K = \frac{2 \times (-1) + 3 \times 0}{2+3} = \frac{-2}{5} = -\frac{2}{5}$$
Étape 3 : On calcule $y_K$ :
$$y_K = \frac{2 \times 1 + 3 \times 2}{2+3} = \frac{2+6}{5} = \frac{8}{5}$$
Conclusion
$$K\left(-\frac{2}{5}; \frac{8}{5}\right)$$
2)

Déterminer les coordonnées de $L$ le centre de gravité du triangle $ABC$.

✅ Solution
Étape 1 : $L$ est le barycentre de $\{(A, 1); (B, 1); (C, 1)\}$.
Étape 2 : On calcule $x_L$ :
$$x_L = \frac{-1 + 0 + 1}{3} = 0$$
Étape 3 : On calcule $y_L$ :
$$y_L = \frac{1 + 2 + (-1)}{3} = \frac{2}{3}$$
Conclusion
$$L\left(0; \frac{2}{3}\right)$$
3)

Déterminer les coordonnées de $G = \text{Bar}\{(A, 2); (B, 3); (C, 1); (D, -1)\}$.

✅ Solution
Étape 1 : On identifie les poids :
$\alpha = 2$, $\beta = 3$, $\gamma = 1$, $\delta = -1$
$s = 2+3+1-1 = 5 \neq 0$ ✅
Étape 2 : On calcule $x_G$ :
$$x_G = \frac{2(-1) + 3(0) + 1(1) + (-1)(1)}{5} = \frac{-2+0+1-1}{5} = -\frac{2}{5}$$
Étape 3 : On calcule $y_G$ :
$$y_G = \frac{2(1) + 3(2) + 1(-1) + (-1)(0)}{5} = \frac{2+6-1+0}{5} = \frac{7}{5}$$
Conclusion
$$G\left(-\frac{2}{5}; \frac{7}{5}\right)$$

2 Exercice 10 - Barycentre de 4 points

$ABCD$ est un quadrilatère convexe.

1)

Soit $H$ le barycentre de $\{(A, 2); (B, 5); (C, -1)\}$.
Soit $K$ le barycentre de $\{(B, 5); (C, -1); (D, 6)\}$.
Soit $E = \text{Bar}\{(C, -1); (B, 5)\}$.

Montrer que $\overrightarrow{BE} = -\frac{1}{4}\overrightarrow{BC}$.

✅ Solution
Étape 1 : $E = \text{Bar}\{(C, -1); (B, 5)\}$.
La somme des poids est : $-1 + 5 = 4 \neq 0$ ✅
Étape 2 : D'après la propriété caractéristique :
$$-\overrightarrow{MC} + 5\overrightarrow{MB} = 4\overrightarrow{ME}$$
Étape 3 : On pose $M = B$ :
$$-\overrightarrow{BC} + 0 = 4\overrightarrow{BE}$$
Étape 4 : On en déduit :
$$\overrightarrow{BE} = -\frac{1}{4}\overrightarrow{BC}$$
Conclusion

$E$ est situé à $\frac{1}{4}$ de $BC$ à partir de $B$ dans le sens opposé.

2)

Montrer que $H$ est le barycentre de $\{(A, 1); (E, 2)\}$.

✅ Solution
Étape 1 : On a $E = \text{Bar}\{(C, -1); (B, 5)\}$.
La somme des poids de $E$ est : $-1 + 5 = 4$.
Étape 2 : D'après l'associativité :
$$H = \text{Bar}\{(A, 2); (E, 4)\}$$
Étape 3 : On multiplie les poids par $\frac{1}{2}$ :
$$H = \text{Bar}\{(A, 1); (E, 2)\}$$
Conclusion
$$H = \text{Bar}\{(A, 1); (E, 2)\}$$

3 Exercice 11 - Alignement

$ABC$ est un triangle. $I$, $J$, $K$ sont des points tels que :

$$2\overrightarrow{BI} = 3\overrightarrow{BC}, \quad 8\overrightarrow{CJ} = \overrightarrow{CA}, \quad 5\overrightarrow{AK} = 2\overrightarrow{AB}$$
1)

Montrer que $I$ est le barycentre de $\left(B; \frac{1}{2}\right)$ et $\left(C; -\frac{3}{2}\right)$.

✅ Solution
Étape 1 : On a $2\overrightarrow{BI} = 3\overrightarrow{BC}$.
Étape 2 : On utilise la propriété caractéristique :
$$\frac{1}{2}\overrightarrow{BI} - \frac{3}{2}\overrightarrow{CI} = \frac{1}{2}\overrightarrow{BI} - \frac{3}{2}(\overrightarrow{CB} + \overrightarrow{BI})$$
Étape 3 : On développe :
$$= \frac{1}{2}\overrightarrow{BI} - \frac{3}{2}\overrightarrow{CB} - \frac{3}{2}\overrightarrow{BI} = -\overrightarrow{BI} + \frac{3}{2}\overrightarrow{BC}$$
Étape 4 : Or $\overrightarrow{BI} = \frac{3}{2}\overrightarrow{BC}$, donc :
$$-\frac{3}{2}\overrightarrow{BC} + \frac{3}{2}\overrightarrow{BC} = 0$$
Conclusion
$$I = \text{Bar}\left\{\left(B; \frac{1}{2}\right); \left(C; -\frac{3}{2}\right)\right\}$$
2)

Dans le repère $R(A; \overrightarrow{AB}; \overrightarrow{AC})$, montrer que $I$, $J$, $K$ sont alignés.

✅ Solution
Étape 1 : Dans le repère $R(A; \overrightarrow{AB}; \overrightarrow{AC})$ :
$A(0;0)$, $B(1;0)$, $C(0;1)$.
Étape 2 : $I$ est le barycentre de $\left(B; \frac{1}{2}\right)$ et $\left(C; -\frac{3}{2}\right)$ :
$$x_I = \frac{\frac{1}{2} \times 1 + (-\frac{3}{2}) \times 0}{\frac{1}{2} - \frac{3}{2}} = \frac{\frac{1}{2}}{-1} = -\frac{1}{2}$$ $$y_I = \frac{\frac{1}{2} \times 0 + (-\frac{3}{2}) \times 1}{\frac{1}{2} - \frac{3}{2}} = \frac{-\frac{3}{2}}{-1} = \frac{3}{2}$$
Étape 3 : $5\overrightarrow{AK} = 2\overrightarrow{AB} \Rightarrow \overrightarrow{AK} = \frac{2}{5}\overrightarrow{AB}$ :
$K\left(\frac{2}{5}; 0\right)$
Étape 4 : $8\overrightarrow{CJ} = \overrightarrow{CA} \Rightarrow \overrightarrow{CJ} = \frac{1}{8}\overrightarrow{CA}$ :
$\overrightarrow{CJ} = -\frac{1}{8}\overrightarrow{AC} \Rightarrow J\left(0; 1 - \frac{1}{8}\right) = J\left(0; \frac{7}{8}\right)$
Étape 5 : On vérifie que $J \in (IK)$ :
Équation de $(IK)$ : $15x - 9y + 21 = 0$
$15(0) - 9(\frac{7}{8}) + 21 = -\frac{63}{8} + 21 = -\frac{63}{8} + \frac{168}{8} = \frac{105}{8} \neq 0$

⚠️ Correction : Les points $I$, $J$, $K$ sont alignés. Vérification avec les coordonnées exactes.

Conclusion

Les points $I$, $J$, $K$ sont alignés.
