Exercice 8

Récurrence - Sommes Niveau : Difficile

8 Récurrence - Partie 2

Montrer par récurrence les formules de sommes suivantes.

g.
$\forall n \in \mathbb{N} : 1 + 3 + 5 + \cdots + (2n+1) = \sum_{i=0}^{n} (2i+1) = (n+1)^2$
✅ Solution

Initialisation : $n=0$

Étape : $\sum_{i=0}^{0} (2i+1) = 1 = (0+1)^2 = 1$ ✅

Hérédité : Supposons que $\sum_{i=0}^{n} (2i+1) = (n+1)^2$.

Étape 1 : $\sum_{i=0}^{n+1} (2i+1) = \sum_{i=0}^{n} (2i+1) + (2n+3)$
Étape 2 : $= (n+1)^2 + 2n + 3$
Étape 3 : $= n^2 + 2n + 1 + 2n + 3$
Étape 4 : $= n^2 + 4n + 4 = (n+2)^2$

Conclusion : La formule est vraie pour tout $n \in \mathbb{N}$.

h.
$\forall n \in \mathbb{N}^* : \sum_{i=1}^{n} \frac{1}{i(i+1)} = \frac{n}{n+1}$
✅ Solution

Initialisation : $n=1$

Étape : $\frac{1}{1 \times 2} = \frac{1}{2} = \frac{1}{1+1}$ ✅

Hérédité : Supposons que $\sum_{i=1}^{n} \frac{1}{i(i+1)} = \frac{n}{n+1}$.

Étape 1 : $\sum_{i=1}^{n+1} \frac{1}{i(i+1)} = \frac{n}{n+1} + \frac{1}{(n+1)(n+2)}$
Étape 2 : $= \frac{n(n+2) + 1}{(n+1)(n+2)}$
Étape 3 : $= \frac{n^2 + 2n + 1}{(n+1)(n+2)}$
Étape 4 : $= \frac{(n+1)^2}{(n+1)(n+2)} = \frac{n+1}{n+2}$

Conclusion : La formule est vraie pour tout $n \in \mathbb{N}^*$.

i.
$\forall n \in \mathbb{N}^* : \sum_{i=1}^{n} \frac{1}{(2i-1)(2i+1)} = \frac{n}{2n+1}$
✅ Solution

Initialisation : $n=1$

Étape : $\frac{1}{1 \times 3} = \frac{1}{3} = \frac{1}{2(1)+1}$ ✅

Hérédité : Supposons que $\sum_{i=1}^{n} \frac{1}{(2i-1)(2i+1)} = \frac{n}{2n+1}$.

Étape 1 : $\sum_{i=1}^{n+1} \frac{1}{(2i-1)(2i+1)} = \frac{n}{2n+1} + \frac{1}{(2n+1)(2n+3)}$
Étape 2 : $= \frac{n(2n+3) + 1}{(2n+1)(2n+3)}$
Étape 3 : $= \frac{2n^2 + 3n + 1}{(2n+1)(2n+3)}$
Étape 4 : $= \frac{(2n+1)(n+1)}{(2n+1)(2n+3)} = \frac{n+1}{2n+3}$

Conclusion : La formule est vraie pour tout $n \in \mathbb{N}^*$.

j.
$\forall n \in \mathbb{N}^* : \sum_{k=1}^{n} k(k+2) = \frac{n(n+1)(2n+7)}{6}$
✅ Solution

Initialisation : $n=1$

Étape : $1 \times 3 = 3$
Étape : $\frac{1 \times 2 \times 9}{6} = \frac{18}{6} = 3$ ✅

Hérédité : Supposons que $\sum_{k=1}^{n} k(k+2) = \frac{n(n+1)(2n+7)}{6}$.

Étape 1 : $\sum_{k=1}^{n+1} k(k+2) = \frac{n(n+1)(2n+7)}{6} + (n+1)(n+3)$
Étape 2 : $= \frac{(n+1)}{6}[n(2n+7) + 6(n+3)]$
Étape 3 : $= \frac{(n+1)}{6}[2n^2 + 7n + 6n + 18]$
Étape 4 : $= \frac{(n+1)}{6}[2n^2 + 13n + 18]$
Étape 5 : $= \frac{(n+1)(n+2)(2n+9)}{6}$

Conclusion : La formule est vraie pour tout $n \in \mathbb{N}^*$.

k.
$\forall n \in \mathbb{N}^* : \sum_{k=1}^{n} (k^2 + k) = \frac{n(n+1)(n+2)}{3}$
✅ Solution

Remarque : $\sum_{k=1}^{n} (k^2 + k) = \sum_{k=1}^{n} k(k+1)$

Initialisation : $n=1$

Étape : $1 \times 2 = 2$
Étape : $\frac{1 \times 2 \times 3}{3} = 2$ ✅

Hérédité : Supposons que $\sum_{k=1}^{n} k(k+1) = \frac{n(n+1)(n+2)}{3}$.

Étape 1 : $\sum_{k=1}^{n+1} k(k+1) = \frac{n(n+1)(n+2)}{3} + (n+1)(n+2)$
Étape 2 : $= \frac{(n+1)(n+2)}{3}(n + 3)$
Étape 3 : $= \frac{(n+1)(n+2)(n+3)}{3}$

Conclusion : La formule est vraie pour tout $n \in \mathbb{N}^*$.
