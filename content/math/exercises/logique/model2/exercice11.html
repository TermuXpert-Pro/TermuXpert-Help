Section 11 : Raisonnement par disjonction des cas

Cours : Partie 4 · §4 Du plus simple au plus difficile

À retenir du cours

Principe : pour montrer $P\Rightarrow R$, on décompose $P$ en plusieurs cas $P_1,\dots,P_k$ qui recouvrent toutes les possibilités ($P\iff P_1\lor\cdots\lor P_k$), puis on montre $P_i\Rightarrow R$ pour chaque cas $i$.

Justification : $\left[(P_1\Rightarrow R)\land\cdots\land(P_k\Rightarrow R)\right]\iff\left[(P_1\lor\cdots\lor P_k)\Rightarrow R\right]$ (vu à l'exercice 7.4 d) pour deux cas).

Cas fréquents : parité d'un entier (pair / impair) ; signe d'un réel (positif / négatif) ; valeur absolue ($x\geqslant0$ / $x\lt 0$).

11.1 Disjonction des cas avec une valeur absolue Facile

Montrer que $\forall x\in\mathbb{R},\ |x|\geqslant x$, en distinguant deux cas.

1)

1er cas : $x\geqslant0$.

✅ Solution détaillée
On a : si $x\geqslant0$, alors $|x|=x$.
Conclusion

$|x|-x=x-x=0\geqslant0$.

2)

2e cas : $x\lt 0$.

✅ Solution détaillée
On a : si $x\lt 0$, alors $|x|=-x$.
Conclusion

$|x|-x=-x-x=-2x$. Comme $x\lt 0$, $-2x>0$, donc $|x|-x>0\geqslant0$.

3)

Conclure.

✅ Solution détaillée
On a : tout réel $x$ vérifie $x\geqslant0$ ou $x\lt 0$ (disjonction complète des cas).
Conclusion

Dans les deux cas, $|x|\geqslant x$ : donc $\forall x\in\mathbb{R},\ |x|\geqslant x$.

11.2 Disjonction des cas avec la parité Facile

Montrer que pour tout $n\in\mathbb{N}$, le produit $n(n+1)$ est pair.

1)

1er cas : $n$ pair. Montrer que $n(n+1)$ est pair.

✅ Solution détaillée
On a : $n=2k$ avec $k\in\mathbb{N}$.
Conclusion

$n(n+1)=2k(n+1)=2\times[k(n+1)]$ : produit pair.

2)

2e cas : $n$ impair. Montrer que $n(n+1)$ est pair.

✅ Solution détaillée
On a : $n$ impair, donc $n+1$ est pair : $n+1=2k$ avec $k\in\mathbb{N}$.
Conclusion

$n(n+1)=n\times2k=2\times(nk)$ : produit pair.

3)

Conclure.

✅ Solution détaillée
On a : tout entier $n$ est pair ou impair (disjonction complète).
Conclusion

Dans les deux cas $n(n+1)$ est pair : le produit de deux entiers consécutifs est toujours pair.

11.3 Équation avec valeur absolue Moyen

Résoudre dans $\mathbb{R}$ l'équation $|x-2|=3$, en distinguant deux cas.

1)

1er cas : $x\geqslant2$. Résoudre l'équation dans ce cas.

✅ Solution détaillée
Dans ce cas : $x-2\geqslant0$, donc $|x-2|=x-2$.
L'équation devient : $x-2=3\iff x=5$.
Vérification : $5\geqslant2$ ✔ : $x=5$ est une solution du premier cas.
Conclusion

Dans ce cas, l'unique solution est $x=5$.

2)

2e cas : $x\lt 2$. Résoudre l'équation dans ce cas.

✅ Solution détaillée
Dans ce cas : $x-2\lt 0$, donc $|x-2|=-(x-2)=2-x$.
L'équation devient : $2-x=3\iff x=-1$.
Vérification : $-1\lt 2$ ✔ : $x=-1$ est une solution du deuxième cas.
Conclusion

Dans ce cas, l'unique solution est $x=-1$.

3)

Conclure en donnant l'ensemble des solutions.

✅ Solution détaillée
On a : tout réel $x$ vérifie $x\geqslant2$ ou $x\lt 2$ ; chaque solution trouvée vérifie bien la condition de son cas.
Conclusion

L'ensemble des solutions de $|x-2|=3$ est $\{-1\,;5\}$.

11.4 Disjonction en trois cas : reste modulo 3 Difficile

Soit $n\in\mathbb{N}$. Tout entier $n$ est, dans la division par $3$, de l'une des trois formes suivantes : $n=3k$, $n=3k+1$ ou $n=3k+2$ (avec $k\in\mathbb{N}$).

1)

Cas $n\equiv0\pmod3$ (c'est-à-dire $n=3k$). Calculer $n^2\bmod3$.

✅ Solution détaillée
On a : $n=3k$, donc $n^2=9k^2=3\times(3k^2)$.
Conclusion

$n^2$ est un multiple de $3$ : $n^2\equiv0\pmod3$.

2)

Cas $n\equiv1\pmod3$ (c'est-à-dire $n=3k+1$). Calculer $n^2\bmod3$.

✅ Solution détaillée
On a : $n^2=(3k+1)^2=9k^2+6k+1=3(3k^2+2k)+1$.
Conclusion

$n^2\equiv1\pmod3$ (reste $1$ dans la division par $3$).

3)

Cas $n\equiv2\pmod3$ (c'est-à-dire $n=3k+2$). Calculer $n^2\bmod3$.

✅ Solution détaillée
On a : $n^2=(3k+2)^2=9k^2+12k+4=3(3k^2+4k+1)+1$.
Conclusion

$n^2\equiv1\pmod3$ (reste $1$).

4)

En déduire que $n^2$ n'est jamais de la forme $3m+2$, puis que si $n^2$ est divisible par $3$, alors $n$ l'est aussi.

✅ Solution détaillée
Bilan des trois cas : $n^2\equiv0$ ou $1\pmod3$, jamais $\equiv2\pmod3$.
Conclusion

$n^2$ n'est jamais de la forme $3m+2$. De plus, par contraposée du cas 1) et vu que les cas 2) et 3) donnent $n^2\not\equiv0\pmod3$ quand $n\not\equiv0\pmod3$ : si $3\mid n^2$, alors nécessairement $n\equiv0\pmod3$, c'est-à-dire $3\mid n$.
