Partie 4 : Étude des fonctions de référence

1 Fonction $f(x) = ax^3$ $(a \neq 0)$

Cas $a > 0$

$f$ est strictement croissante sur $\mathbb{R}$.

Cas $a < 0$

$f$ est strictement décroissante sur $\mathbb{R}$.

Propriétés
  • $D_f = \mathbb{R}$
  • $f$ est impaire : $f(-x) = -f(x)$
  • Ensemble d'étude : $D_E = \mathbb{R}^+$
Résumé
  • $a > 0$ : $f$ est strictement croissante sur $\mathbb{R}$.
  • $a < 0$ : $f$ est strictement décroissante sur $\mathbb{R}$.

2 Fonction $f(x) = \sqrt{x} + a$

Étude
  • $D_f = [0, +\infty[$
  • $f$ est strictement croissante sur $D_f$.
$$x < x' \Rightarrow \sqrt{x} < \sqrt{x'} \Rightarrow f(x) < f(x')$$

📈 $f(x) = \sqrt{x} + a$

$f(x) = \sqrt{x}$ (a=0)

Résumé
  • $D_f = [0, +\infty[$
  • $f$ est strictement croissante sur $[0, +\infty[$
