Logique mathématique

1 Proposition

Définition

Une proposition est une phrase soit vraie, soit fausse, pas les deux en même temps.

Exemples :

  • « \(2 + 2 = 4\) » est une proposition vraie.
  • « \(3 \times 5 = 10\) » est une proposition fausse.
  • « Il fait beau aujourd'hui » n'est pas une proposition (dépend du contexte).
Résumé
  • Une proposition est une phrase qui a une valeur de vérité.
  • Valeur possible : vraie ou fausse.

3 Lois logiques (Tautologies)

Définition

Une loi logique (ou tautologie) est une proposition toujours vraie.

Propriétés fondamentales

Soient $P$, $Q$, $R$ trois propositions. Nous avons les équivalences suivantes :

1. $P \Leftrightarrow \neg(\neg P)$

2. $(P \land Q) \Leftrightarrow (Q \land P)$

3. $(P \lor Q) \Leftrightarrow (Q \lor P)$

4. $\neg(P \land Q) \Leftrightarrow (\neg P) \lor (\neg Q)$

5. $\neg(P \lor Q) \Leftrightarrow (\neg P) \land (\neg Q)$

6. $P \land (Q \lor R) \Leftrightarrow (P \land Q) \lor (P \land R)$

7. $P \lor (Q \land R) \Leftrightarrow (P \lor Q) \land (P \lor R)$

8. $(P \Rightarrow Q) \Leftrightarrow (\neg Q \Rightarrow \neg P)$

Remarque

Les lois 4 et 5 sont les lois de Morgan.

La loi 8 est la contraposée.

Résumé
  • Les lois logiques sont toujours vraies.
  • Les plus importantes : lois de Morgan et contraposée.

4 Quantificateurs

4-1 Universel « pour tout » ($\forall$)

Définition

« $\forall x \in E : P(x)$ » se lit « Pour tout $x$ dans $E$, $P(x)$ est vraie ».

Exemple :

« $\forall x \in [1; +\infty[ : x^2 \ge 1$ » est vraie.

4-2 Existentiel « il existe » ($\exists$)

Définition

« $\exists x \in E : P(x)$ » se lit « Il existe $x$ dans $E$ tel que $P(x)$ est vraie ».

Exemples :

  • « $\exists n \in \mathbb{N} : n^2 - n \ge n$ » est vraie (ex: $n=3$).
  • « $\exists x \in \mathbb{R} : x^2 = -1$ » est fausse.

4-3 Négation des quantificateurs

$\neg(\forall x \in E : P(x)) \Leftrightarrow \exists x \in E : \neg P(x)$

$\neg(\exists x \in E : P(x)) \Leftrightarrow \forall x \in E : \neg P(x)$

Remarque

Pour nier : on change « pour tout » en « il existe » et inversement.

Résumé
  • $\forall$ = "pour tout" → universel.
  • $\exists$ = "il existe" → existentiel.
  • Négation : on échange $\forall$ et $\exists$.

5 Raisonnements

5.1 Raisonnement direct

Principe

Pour montrer $P \Rightarrow Q$, on suppose P vraie et on montre Q vraie.

Exemple :

Montrer : $\begin{cases} 0 \le x < 2 \\ 0 \le y < 2 \end{cases} \Rightarrow \frac{1}{x} + \frac{1}{y} > 1$

Étape 1 : $0 \le x < 2 \Rightarrow \frac{1}{x} \ge \frac{1}{2}$
Étape 2 : $0 \le y < 2 \Rightarrow \frac{1}{y} \ge \frac{1}{2}$
Étape 3 : $\Rightarrow \frac{1}{x} + \frac{1}{y} > 1$

5.2 Disjonction des cas

Principe

On montre pour une partie A de E, puis pour le reste.

Exemple :

Montrer : $\forall x \in \mathbb{R} : |x-1| \le x^2 - x + 1$

Cas 1 : $x \ge 1 \Rightarrow |x-1| = x-1$

Étape : $(x^2 - x + 1) - (x-1) = (x-1)^2 + 1 \ge 0$

Cas 2 : $x < 1 \Rightarrow |x-1| = -(x-1)$

Étape : $(x^2 - x + 1) + (x-1) = x^2 \ge 0$

Conclusion : L'inégalité est vraie dans les deux cas.

5.3 Contraposition

Rappel

Utile quand la preuve directe est difficile.

Principe

$(P \Rightarrow Q) \Leftrightarrow (\neg Q \Rightarrow \neg P)$

Exemple :

Montrer : $x \neq -8 \Rightarrow \frac{x+2}{x+5} \neq 2$

Par contraposition : montrons $\frac{x+2}{x+5} = 2 \Rightarrow x = -8$

Étape 1 : $\frac{x+2}{x+5} = 2 \Rightarrow x+2 = 2(x+5)$
Étape 2 : $\Rightarrow x+2 = 2x+10 \Rightarrow x = -8$

Conclusion : La proposition est vraie.

5.4 Raisonnement par l'absurde

Rappel

Puissant, nécessite de bien identifier la contradiction.

Principe

Pour montrer $P \Rightarrow Q$, on suppose P vraie et Q fausse, on cherche une contradiction.

Exemple :

Montrer : $\frac{a}{1+b} = \frac{b}{1+a} \Rightarrow a = b$ (avec $a,b > 0$).

Étape 1 : Supposons $\frac{a}{1+b} = \frac{b}{1+a}$ et $a \neq b$.
Étape 2 : $a(1+a) = b(1+b) \Rightarrow a^2 - b^2 = b - a$
Étape 3 : $(a-b)(a+b) = -(a-b) \Rightarrow a+b = -1$

Contradiction car $a+b > 0$.

Conclusion : $a = b$.

5.5 Contre-exemple

Principe

Pour montrer $\forall x \in E : P(x)$ est fausse, il suffit de trouver un contre-exemple.

Exemple :

Montrer que $P : (\forall x \in [0;1]) : x^2 \ge x$ est fausse.

Contre-exemple : $x = \frac{1}{2}$
Vérification : $\left(\frac{1}{2}\right)^2 = \frac{1}{4} < \frac{1}{2}$

Conclusion : $P$ est fausse.

5.6 Équivalence

Principe

Pour montrer P vraie, on montre $P \Leftrightarrow Q$ et Q vraie.

Exemple :

Montrer : $\forall x > 0 : x + \frac{1}{x} \ge 2$

Étape 1 : $x + \frac{1}{x} \ge 2 \Leftrightarrow \frac{x^2+1}{x} \ge 2$
Étape 2 : $\Leftrightarrow \frac{x^2+1-2x}{x} \ge 0$
Étape 3 : $\Leftrightarrow \frac{(x-1)^2}{x} \ge 0$

Comme $(x-1)^2 \ge 0$ et $x > 0$, l'inégalité est vraie.

Conclusion : La proposition est vraie.

5.7 Récurrence

Rappel

Méthode fondamentale pour prouver des propriétés sur les entiers naturels.

Principe

Pour montrer $P(n)$ vraie $\forall n \in \mathbb{N}$ :

  • Initialisation : $P(0)$ vraie.
  • Hérédité : $P(n) \Rightarrow P(n+1)$.

Exemple :

Montrer : $\forall n \in \mathbb{N} : n^3 + 2n$ divisible par 3.

Initialisation : $n=0 \Rightarrow 0$ divisible par 3. ✅

Hérédité : Supposons $\exists k / n^3 + 2n = 3k$

Étape 1 : $(n+1)^3 + 2(n+1) = (n^3+2n) + 3n^2 + 3n + 3$
Étape 2 : $= 3k + 3(n^2+n+1) = 3(k+n^2+n+1)$

Conclusion : La propriété est vraie pour tout $n \in \mathbb{N}$.

Résumé des raisonnements
  • Direct : On suppose P, on montre Q.
  • Disjonction : On traite tous les cas.
  • Contraposition : On montre $\neg Q \Rightarrow \neg P$.
  • Absurde : On suppose P et $\neg Q$, contradiction.
  • Contre-exemple : On trouve un cas qui contredit.
  • Équivalence : On montre $P \Leftrightarrow Q$ et Q vraie.
  • Récurrence : Initialisation + hérédité.

$\neg P \lor \neg Q \equiv \neg(P \land Q)$ (loi de Morgan).

Exercice 2 :

Montrer par contraposition : $x^2$ pair $\Rightarrow x$ pair ($x \in \mathbb{Z}$).

Voir la solution
Étape 1 : Contraposition : $x$ impair $\Rightarrow x^2$ impair.
Étape 2 : $x = 2k+1 \Rightarrow x^2 = 4k^2+4k+1 = 2(2k^2+2k)+1$.
Étape 3 : Donc $x^2$ est impair.

Conclusion : La proposition est vraie.

Exercice 3 :

Montrer par récurrence : $\forall n \in \mathbb{N} : 2^n \ge n+1$.

Voir la solution

Initialisation : $n=0 \Rightarrow 2^0 = 1 \ge 1$ ✅

Hérédité : Supposons $2^n \ge n+1$.

Étape 1 : $2^{n+1} = 2 \times 2^n \ge 2(n+1)$
Étape 2 : $2n+2 \ge n+2$ (car $n \ge 0$)

Conclusion : La propriété est vraie pour tout $n \in \mathbb{N}$.
