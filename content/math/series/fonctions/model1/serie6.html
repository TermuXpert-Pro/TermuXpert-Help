41 Périodicité

1) Quelle est la période des fonctions suivantes :

a)

$f(x) = \sin(4x-1)$

✅ Solution
On a : la période de $\sin(ax+b)$ est $T = \dfrac{2\pi}{|a|}$
D'où : ici $a = 4$, donc $T = \dfrac{2\pi}{4} = \dfrac{\pi}{2}$

Conclusion : $T = \dfrac{\pi}{2}$

b)

$g(x) = \cos(5x)$

✅ Solution
On a : la période de $\cos(ax)$ est $T = \dfrac{2\pi}{|a|}$
D'où : ici $a = 5$, donc $T = \dfrac{2\pi}{5}$

Conclusion : $T = \dfrac{2\pi}{5}$

2)

Trouver une fonction de période $T = \dfrac{3}{4}$

✅ Solution
On cherche : $f(x) = \sin(ax)$ avec $T = \dfrac{2\pi}{a} = \dfrac{3}{4}$
D'où : $a = \dfrac{2\pi}{3/4} = \dfrac{8\pi}{3}$

Conclusion : $f(x) = \sin\left(\dfrac{8\pi}{3}x\right)$ a pour période $T = \dfrac{3}{4}$.

42 Fonction périodique

Soit f une fonction périodique de période $T=2$ telle que $f(x)=2x-x^2$ pour $x \in [0;2]$

1)

Tracer la représentation graphique sur $[-2;8]$

✅ Solution

La fonction est périodique de période 2, donc la courbe se répète tous les 2 unités.

Périodicité de $f(x) = 2x - x^2$ sur $[0;2]$

2)

Calculer $f(4.1)$, $f(-3.5)$, $f(265.11)$

✅ Solution
On a : $f(4.1) = f(4.1 - 4) = f(0.1)$ car $T=2$
$f(0.1) = 2(0.1) - (0.1)^2 = 0.2 - 0.01 = 0.19$
De même : $f(-3.5) = f(-3.5 + 4) = f(0.5)$
$f(0.5) = 2(0.5) - (0.5)^2 = 1 - 0.25 = 0.75$
Enfin : $f(265.11) = f(265.11 - 264) = f(1.11)$
$f(1.11) = 2(1.11) - (1.11)^2 = 2.22 - 1.2321 = 0.9879$

Conclusion :

  • $f(4.1) = 0.19$
  • $f(-3.5) = 0.75$
  • $f(265.11) = 0.9879$
3)

Donner l'expression de f sur $I_k = [2k; 2(k+1)]$

✅ Solution
On a : pour $x \in [2k; 2(k+1)]$, $x-2k \in [0;2]$
D'où : $f(x) = f(x-2k) = 2(x-2k) - (x-2k)^2$

Conclusion : $f(x) = 2(x-2k) - (x-2k)^2$ pour $x \in [2k; 2(k+1)]$

43 Résolutions graphiques

Soit $f(x) = x^3 - 4x^2 + 3$ et la droite $(D): y = -x - 3$

1)

Résoudre graphiquement $f(x) = 3$ puis $f(x) < 3$

✅ Solution
On a : $f(x) = 3 \iff x^3 - 4x^2 + 3 = 3 \iff x^3 - 4x^2 = 0 \iff x^2(x-4) = 0$
D'où : $x = 0$ ou $x = 4$
De même : $f(x) < 3 \iff x^3 - 4x^2 < 0 \iff x^2(x-4) < 0 \iff x \in ]-\infty; 0[ \cup ]0; 4[$

Conclusion :

  • $f(x) = 3 \iff x \in \{0, 4\}$
  • $f(x) < 3 \iff x \in ]-\infty; 0[ \cup ]0; 4[$
2)

Résoudre graphiquement $f(x) = 0$ puis $f(x) \ge 0$

✅ Solution
On a : $f(x) = 0 \iff x^3 - 4x^2 + 3 = 0$
Or : $x = 1$ est une racine : $1 - 4 + 3 = 0$ ✅
Donc : $x^3 - 4x^2 + 3 = (x-1)(x^2 - 3x - 3)$
D'où : $x^2 - 3x - 3 = 0 \iff x = \dfrac{3 \pm \sqrt{9+12}}{2} = \dfrac{3 \pm \sqrt{21}}{2}$

Conclusion : $f(x) \ge 0 \iff x \in \left[\dfrac{3-\sqrt{21}}{2}; 1\right] \cup \left[\dfrac{3+\sqrt{21}}{2}; +\infty\right[$

3)

Résoudre graphiquement $f(x) = -x-3$ puis $f(x) \le -x-3$

✅ Solution
On a : $f(x) = -x-3 \iff x^3 - 4x^2 + 3 = -x-3 \iff x^3 - 4x^2 + x + 6 = 0$
Or : $x = 2$ est une racine : $8 - 16 + 2 + 6 = 0$ ✅
D'où : $x^3 - 4x^2 + x + 6 = (x-2)(x^2 - 2x - 3) = (x-2)(x-3)(x+1)$

Conclusion :

  • $f(x) = -x-3 \iff x \in \{-1, 2, 3\}$
  • $f(x) \le -x-3 \iff x \in ]-\infty; -1] \cup [2; 3]$

44 Résolutions graphiques et algébriques

Soit $f(x) = x^2 - 3x - 4$ et $g(x) = 3x + 12$

2)

Résoudre algébriquement $f(x) = g(x)$

✅ Solution
On a : $x^2 - 3x - 4 = 3x + 12$
Donc : $x^2 - 6x - 16 = 0$
On calcule : $\Delta = 36 + 64 = 100$
D'où : $x_1 = \dfrac{6-10}{2} = -2$, $x_2 = \dfrac{6+10}{2} = 8$

✅ Solution

Donc : $x^2 - 6x - 16 \ge 0$
On factorise : $(x+2)(x-8) \ge 0$
D'où : Tableau de signe :
$x$$-\infty$$-2$$8$$+\infty$
$x+2$−0+++
$x-8$−−−0+

Conclusion : $S = ]-\infty, -2] \cup [8, +\infty[$

4)

Trouver les points d'intersection de $(C_f)$ avec les axes

✅ Solution
Axe des abscisses (y = 0) : $x^2 - 3x - 4 = 0 \iff (x-4)(x+1) = 0$
$x = 4$ ou $x = -1$

  • Axe des ordonnées : $C(0,-4)$

45 Tableaux de variations et intersections

Soit $f(x) = -x^2 - 2x + 3$ et $g(x) = \dfrac{x-1}{x+2}$

1)

Dresser le tableau de variations de f et g

✅ Solution

Pour f :

On a : $f'(x) = -2x - 2 = -2(x+1)$
$x$$-\infty$$-1$$+\infty$
$f'(x)$+$0$−
$f(x)$$\nearrow$$4$$\searrow$

Pour g :

On a : $D_g = \mathbb{R} \setminus \{-2\}$
D'où : $g'(x) = \dfrac{1(x+2) - (x-1)}{(x+2)^2} = \dfrac{x+2-x+1}{(x+2)^2} = \dfrac{3}{(x+2)^2} > 0$
$x$$-\infty$$-2$$+\infty$
$g'(x)$+||+
$g(x)$$\nearrow$||$\nearrow$

Conclusion :

  • f : croissante sur $]-\infty, -1]$, décroissante sur $[-1, +\infty[$
  • g : strictement croissante sur $]-\infty, -2[$ et sur $]-2, +\infty[$
2a)

Trouver les points d'intersection de $(C_f)$ avec l'axe des abscisses

✅ Solution
On a : $f(x) = 0 \iff -x^2 - 2x + 3 = 0 \iff x^2 + 2x - 3 = 0$
D'où : $(x+3)(x-1) = 0 \iff x = -3$ ou $x = 1$

Conclusion : Points : $A(-3,0)$ et $B(1,0)$

2b)

Trouver le point d'intersection de $(C_g)$ avec l'axe des abscisses

✅ Solution
On a : $g(x) = 0 \iff \dfrac{x-1}{x+2} = 0 \iff x-1 = 0 \iff x = 1$

Conclusion : Point : $C(1,0)$

4a)

Résoudre graphiquement $f(x) = g(x)$

✅ Solution
On a : $f(x) = g(x) \iff -x^2 - 2x + 3 = \dfrac{x-1}{x+2}$
On multiplie par $(x+2)$ : $(-x^2 - 2x + 3)(x+2) = x-1$
Donc : $(-x^2 - 2x + 3)(x+2) - x + 1 = 0$
Après développement : $-x^3 - 4x^2 - 2x + 7 = 0$, soit $x^3 + 4x^2 + 2x - 7 = 0$
Or : $x = 1$ est une racine : $1 + 4 + 2 - 7 = 0$ ✅
D'où : $x^3 + 4x^2 + 2x - 7 = (x-1)(x^2+5x+7)$, avec $\Delta = 25-28 = -3 < 0$ (pas de racine réelle pour le second facteur)

Conclusion : $(C_f)$ et $(C_g)$ se coupent en un seul point, d'abscisse $x = 1$ (on vérifie $f(1) = g(1) = 0$).

46 Fonction minorée et majorée

Soit $f(x) = \sqrt{x} + \sqrt{x} - \sqrt{x}$

1)

Déterminer $D_f$

✅ Solution
On a : $f(x) = \sqrt{x} + \sqrt{x} - \sqrt{x} = \sqrt{x}$
D'où : $\sqrt{x}$ est définie pour $x \ge 0$

Conclusion : $D_f = [0, +\infty[$

2)

Démontrer que f est minorée

✅ Solution
On a : $\sqrt{x} \ge 0$ pour tout $x \ge 0$

Conclusion : $f$ est minorée par $m = 0$.

3)

Démontrer que f est majorée par $\dfrac{1}{2}$ et conclure

✅ Solution
On a : $\sqrt{x}$ n'est pas majorée par $\dfrac{1}{2}$ car pour $x = 1$, $\sqrt{1} = 1 > \dfrac{1}{2}$

Conclusion : L'énoncé contient une erreur, $\sqrt{x}$ n'est pas majorée.

47 Valeur minimale

Soit $f(x) = x^2 + 2x\sqrt{x} + x - 4$

1)

Démontrer que f admet une valeur minimale

✅ Solution
On a : $f(x) = x^2 + 2x\sqrt{x} + x - 4 = (\sqrt{x})^4 + 2(\sqrt{x})^3 + (\sqrt{x})^2 - 4$
On pose : $t = \sqrt{x} \ge 0$, $f(t) = t^4 + 2t^3 + t^2 - 4 = t^2(t+1)^2 - 4$
Donc : $t^2(t+1)^2 \ge 0 \Rightarrow f(t) \ge -4$
Or : $f(0) = -4$

Conclusion : La valeur minimale est $m = -4$ atteinte en $x = 0$.

2)

Démontrer que f n'est pas majorée

✅ Solution
On a : quand $x \to +\infty$, $f(x) \sim x^2 \to +\infty$

Conclusion : $f$ n'est pas majorée sur $[0, +\infty[$.

48 Variations et composée

Soit $g(x) = \dfrac{2x+3}{x-1}$ et $h(x) = x^2 + 2$

1a)

Étudier les variations de g

✅ Solution
On a : $D_g = \mathbb{R} \setminus \{1\}$
D'où : $g'(x) = \dfrac{2(x-1) - (2x+3)}{(x-1)^2} = \dfrac{2x-2-2x-3}{(x-1)^2} = \dfrac{-5}{(x-1)^2} < 0$

Conclusion : $g$ est strictement décroissante sur $]-\infty,1[$ et sur $]1,+\infty[$.

1b)

Étudier le signe de g

✅ Solution
On a : $g(x) = 0 \iff 2x+3 = 0 \iff x = -\dfrac{3}{2}$
$x$$-\infty$$-\frac{3}{2}$$1$$+\infty$
$2x+3$−0+++
$x-1$−−−0+
$g(x)$+0−||+

Conclusion :

  • $g(x) > 0$ sur $]-\infty, -\frac{3}{2}[ \cup ]1, +\infty[$
  • $g(x) < 0$ sur $]-\frac{3}{2}, 1[$
2)

Montrer que $f(x) = (h \circ g)(x)$ où $f(x) = \dfrac{6x^2+8x+11}{(x-1)^2}$

✅ Solution
On a : $(h \circ g)(x) = h(g(x)) = (g(x))^2 + 2 = \left(\dfrac{2x+3}{x-1}\right)^2 + 2$
On met au même dénominateur : $= \dfrac{(2x+3)^2}{(x-1)^2} + 2 = \dfrac{4x^2+12x+9}{(x-1)^2} + \dfrac{2(x-1)^2}{(x-1)^2}$
D'où : $= \dfrac{4x^2+12x+9 + 2x^2 - 4x + 2}{(x-1)^2} = \dfrac{6x^2+8x+11}{(x-1)^2} = f(x)$

Conclusion : $f = h \circ g$ ✅

3)

Étudier les variations de f sur $]1, +\infty[$, $[-\frac{3}{2}, 1[$ et $]-\infty, -\frac{3}{2}]$

✅ Solution
On a : $g$ est décroissante sur chaque intervalle.
Et : $h(x) = x^2 + 2$ est croissante sur $[0, +\infty[$ et décroissante sur $]-\infty, 0]$
D'où : $g(x) > 0$ sur $]-\infty, -\frac{3}{2}[$ et $]1, +\infty[$ ; $g(x) < 0$ sur $]-\frac{3}{2}, 1[$

Conclusion :

  • Sur $]1, +\infty[$ : $g$ décroissante, $g>0$, $h$ croissante → $f$ est décroissante
  • Sur $[-\frac{3}{2}, 1[$ : $g$ décroissante, $g<0$, $h$ décroissante → $f$ est croissante
  • Sur $]-\infty, -\frac{3}{2}]$ : $g$ décroissante, $g>0$, $h$ croissante → $f$ est décroissante
