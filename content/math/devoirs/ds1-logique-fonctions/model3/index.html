Exercice 1 — Logique mathématique

14 pts · 2 pts × 7
1)
Type : Connecteurs logiques (OU / ET)

Déterminer la valeur de vérité des propositions suivantes :

\[ \text{P} : \left( \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5} \text{ ou } "4 \text{ est premier}" \right) \quad ; \quad \text{Q} : \left( 3,7 \notin \mathbb{N} \text{ et } |1 - \sqrt{3}| = 1 - \sqrt{3} \right) \]
✅ Correction
1) Proposition P :

On a \(\frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}\) (vraie, identité classique).

L'assertion "4 est premier" est fausse (\(4 = 2 \times 2\)).

P est de la forme (vraie ou fausse) = vraie.

2) Proposition Q :

\(3,7 \notin \mathbb{N}\) est vraie (3,7 n'est pas un entier naturel).

\(|1-\sqrt{3}| = \sqrt{3}-1\) car \(\sqrt{3} > 1\). Donc \(|1-\sqrt{3}| = 1-\sqrt{3}\) est fausse.

Q est de la forme (vraie et fausse) = fausse.

Conclusion

P est vraie, Q est fausse.

2)
Type : Quantificateurs & contre-exemple

Déterminer la valeur de vérité des propositions suivantes :

\[ \text{R} : \left( (\forall x \in \mathbb{R}), x^2 \ge 3x \right) \quad ; \quad \text{S} : \left( (\exists n \in \mathbb{N}), n^2 - 6n + 9 = 0 \right) \]
✅ Correction
1) Proposition R :

\(x^2 \ge 3x \iff x^2 - 3x \ge 0 \iff x(x-3) \ge 0\).

Cette inégalité est fausse pour \(0 < x < 3\) (par exemple \(x=1\) : \(1 \ge 3\) est faux).

Donc R est fausse.

2) Proposition S :

\(n^2 - 6n + 9 = 0 \iff (n-3)^2 = 0 \iff n = 3\).

Puisque \(3 \in \mathbb{N}\), il existe bien un entier naturel qui vérifie l'équation.

Donc S est vraie.

Conclusion

R est fausse, S est vraie.

3)
Type : Négation & contre-exemple

On considère la proposition suivante :

\[ \text{T} : (\forall x \in \mathbb{R}) \; ; \; \sqrt{x^2 + 4x + 7} = x + 2 \]

a - Donner la négation de T.

b - Déduire que la proposition T est fausse.

✅ Correction
a) Négation de T :
\[ \overline{\text{T}} : (\exists x \in \mathbb{R}) \; ; \; \sqrt{x^2 + 4x + 7} \neq x + 2 \]
b) Déduction :

Il suffit de trouver un contre-exemple. Prenons \(x = 0\). On a :

\[ \sqrt{0^2 + 4(0) + 7} = \sqrt{7} \quad \text{et} \quad 0 + 2 = 2 \]

Puisque \(\sqrt{7} \neq 2\) (car \(\sqrt{7} \approx 2{,}65\)), la proposition T est fausse.

Les courbes \(y=\sqrt{x^2+4x+7}\) et \(y=x+2\) ne coïncident pas : en \(x=0\), un écart net apparaît entre \(\sqrt{7}\) et \(2\).

Conclusion

\(\overline{\text{T}} : \exists x \in \mathbb{R}, \sqrt{x^2+4x+7} \neq x+2\). T est fausse.

4)
Type : Équivalences successives

En utilisant le raisonnement par équivalences successives montrer que :

\[ (\forall x \in \mathbb{R}) : \sqrt{x^4 + 5x^2 + 4} \ge x^2 + 2 \]
✅ Correction
Raisonnement par équivalences successives :

Pour tout \(x \in \mathbb{R}\), \(x^4+5x^2+4>0\) et \(x^2+2>0\). L'inégalité équivaut donc à :

\[ \sqrt{x^4+5x^2+4} \ge x^2+2 \iff x^4+5x^2+4 \ge (x^2+2)^2 \]

Développons le membre de droite :

\[ (x^2+2)^2 = x^4+4x^2+4 \]

L'inégalité devient :

\[ x^4+5x^2+4 \ge x^4+4x^2+4 \iff x^2 \ge 0 \]

Or \(x^2 \ge 0\) est vraie pour tout \(x \in \mathbb{R}\).

Conclusion

L'inégalité est vraie pour tout \(x \in \mathbb{R}\).

Rappel

Pour \(a \ge 0\) et \(b \ge 0\), on a \(a \ge b \iff a^2 \ge b^2\).

5)
Type : Raisonnement par contraposée

En utilisant le raisonnement par la contraposée montrer que :

\[ \forall (x, y) \in \mathbb{R}^{*2} : (x \neq y \text{ et } x \cdot y \neq 3) \Rightarrow \left( \frac{x^2 + 3}{x} \neq \frac{y^2 + 3}{y} \right) \]
✅ Correction
Raisonnement par contraposée :

La contraposée de \(\text{A} \Rightarrow \text{B}\) est \(\overline{\text{B}} \Rightarrow \overline{\text{A}}\). Montrons que :

\[ \frac{x^2+3}{x} = \frac{y^2+3}{y} \Rightarrow (x=y \text{ ou } xy=3) \]
Calcul :
\[ \frac{x^2+3}{x} = \frac{y^2+3}{y} \iff x+\frac{3}{x} = y+\frac{3}{y} \]

On multiplie par \(xy\) (non nul car \(x,y \in \mathbb{R}^*\)) :

\[ x^2y+3y = xy^2+3x \iff x^2y-xy^2+3y-3x=0 \]

On factorise :

\[ xy(x-y)-3(x-y)=0 \iff (x-y)(xy-3)=0 \]

Donc \(x=y\) ou \(xy=3\).

Conclusion

La contraposée est vraie, donc l'implication initiale est vraie.

Rappel

La contraposée de \(A \Rightarrow B\) est \(\overline{B} \Rightarrow \overline{A}\). Les deux sont équivalentes.

6)
Type : Raisonnement par récurrence

En utilisant le raisonnement par récurrence montrer que les deux propositions suivantes sont vraies :

a - \((\forall n \in \mathbb{N}) \quad 1 + 7^1 + 7^2 + \cdots + 7^n = \frac{1}{6}(7^{n+1} - 1)\)

b - Le nombre \(2^{3n+1} + 3^{n+1}\) est divisible par \(5\) pour tout \(n\) de \(\mathbb{N}\).

✅ Correction

a) Somme des puissances de 7

Initialisation (n=0) :
\[ 1 = \frac{1}{6}(7^1-1) = \frac{6}{6} = 1 \]

La propriété est vraie au rang \(n=0\).

Hérédité :

Supposons que pour un \(n \in \mathbb{N}\) fixé, on a \(1+7^1+\cdots+7^n = \frac{1}{6}(7^{n+1}-1)\). Montrons la propriété au rang \(n+1\) :

\[ 1+7^1+\cdots+7^n+7^{n+1} = \frac{1}{6}(7^{n+1}-1) + 7^{n+1} \]
\[ = \frac{7^{n+1}-1+6\cdot7^{n+1}}{6} = \frac{7\cdot7^{n+1}-1}{6} = \frac{7^{n+2}-1}{6} \]

La propriété est bien héréditaire.

Conclusion

Par récurrence, la proposition est vraie pour tout \(n \in \mathbb{N}\).

b) Divisibilité par 5

Initialisation (n=0) :
\[ 2^{1}+3^{1} = 2+3 = 5 \]

5 est divisible par 5. La propriété est vraie au rang \(n=0\).

Hérédité :

Supposons que pour un \(n \in \mathbb{N}\) fixé, \(2^{3n+1}+3^{n+1}\) est divisible par 5, c'est-à-dire qu'il existe \(k \in \mathbb{N}\) tel que \(2^{3n+1}+3^{n+1}=5k\).

Montrons la propriété au rang \(n+1\) :

\[ 2^{3(n+1)+1}+3^{(n+1)+1} = 2^{3n+4}+3^{n+2} = 8\cdot2^{3n+1} + 3\cdot3^{n+1} \]

On utilise l'hypothèse de récurrence \(2^{3n+1} = 5k-3^{n+1}\) :

\[ = 8(5k-3^{n+1}) + 3\cdot3^{n+1} = 40k - 8\cdot3^{n+1} + 3\cdot3^{n+1} = 40k - 5\cdot3^{n+1} \]
\[ = 5(8k - 3^{n+1}) \]

Donc \(2^{3(n+1)+1}+3^{(n+1)+1}\) est divisible par 5.

Conclusion

Par récurrence, \(2^{3n+1}+3^{n+1}\) est divisible par 5 pour tout \(n \in \mathbb{N}\).

Rappel

Le raisonnement par récurrence comporte deux étapes : l'initialisation et l'hérédité.

7)
Type : Raisonnement par l'absurde

En utilisant le raisonnement par l'absurde montrer que :

\[ \forall x \in \mathbb{R}^+ : \sqrt{x} \neq \frac{x+3}{\sqrt{x+6}} \]
✅ Correction
Raisonnement par l'absurde :

Supposons qu'il existe \(x \in \mathbb{R}^+\) tel que :

\[ \sqrt{x} = \frac{x+3}{\sqrt{x+6}} \]

On élève au carré (les deux membres sont positifs) :

\[ x = \frac{(x+3)^2}{x+6} \iff x(x+6) = (x+3)^2 \iff x^2+6x = x^2+6x+9 \]

Ce qui donne \(0 = 9\), ce qui est absurde.

Conclusion

Notre supposition est fausse, donc \(\forall x \in \mathbb{R}^+, \sqrt{x} \neq \frac{x+3}{\sqrt{x+6}}\).

Rappel

Le raisonnement par l'absurde consiste à supposer le contraire de ce que l'on veut montrer et à aboutir à une contradiction.

Exercice 2 — Fonction majorée/minorée

3,5 pts

On considère la fonction \(f\) définie par \(f(x) = \dfrac{-3x+6}{x^2-2x+5}\).

Type : Signe d'un trinôme (discriminant)

1) Montrer que \((\forall x \in \mathbb{R}) \quad x^2-2x+5 > 0\), et déduire \(D_f\).

✅ Correction
Étude du discriminant :

Pour \(x^2-2x+5\), \(\Delta = (-2)^2-4(1)(5) = 4-20 = -16 < 0\).

Le coefficient de \(x^2\) est \(a=1>0\), donc le trinôme est toujours strictement positif sur \(\mathbb{R}\).

Domaine de définition :

Le dénominateur ne s'annulant jamais :

Conclusion

\(\boxed{D_f = \mathbb{R}}\)

Rappel

Pour \(ax^2+bx+c\) avec \(a>0\) et \(\Delta<0\), le trinôme est toujours strictement positif.

Type : Majoration

2) Montrer que \(f\) est majorée par \(3\) sur \(\mathbb{R}\).

✅ Correction
Montrons que \(f(x) \le 3\) pour tout \(x \in \mathbb{R}\) :
\[ f(x) \le 3 \iff \frac{-3x+6}{x^2-2x+5} \le 3 \]

Comme \(x^2-2x+5>0\), on multiplie sans changer le sens :

\[ -3x+6 \le 3(x^2-2x+5) \iff -3x+6 \le 3x^2-6x+15 \iff 0 \le 3x^2-3x+9 \]

Soit \(x^2-x+3 \ge 0\). Discriminant : \(1-12=-11<0\), \(a=1>0\) : toujours vrai.

Conclusion

\(f\) est majorée par 3 sur \(\mathbb{R}\).

Type : Minoration & existence d'un minimum

3) a – Montrer que \(f\) est minorée par \(-2\) sur \(\mathbb{R}\).

b – Est-ce que \(-2\) est une valeur minimale de \(f\) sur \(\mathbb{R}\) ?

✅ Correction

a) Minorée par -2

Montrons que \(f(x) \ge -2\) pour tout \(x \in \mathbb{R}\) :
\[ f(x) \ge -2 \iff \frac{-3x+6}{x^2-2x+5} \ge -2 \]

Comme \(x^2-2x+5>0\), on multiplie sans changer le sens :

\[ -3x+6 \ge -2(x^2-2x+5) \iff -3x+6 \ge -2x^2+4x-10 \iff 2x^2-7x+16 \ge 0 \]

Discriminant : \(49-128=-79<0\), \(a=2>0\) : toujours vrai.

Conclusion

\(f\) est minorée par \(-2\) sur \(\mathbb{R}\).

b) Valeur minimale

Vérification :

Il faudrait \(x_0 \in \mathbb{R}\) tel que \(f(x_0)=-2\) :

\[ f(x)=-2 \iff -3x+6 = -2x^2+4x-10 \iff 2x^2-7x+16=0 \]

Discriminant \(=-79<0\) : aucune solution réelle.

Conclusion

\(-2\) n'est pas une valeur minimale de \(f\) sur \(\mathbb{R}\), car l'équation \(f(x)=-2\) n'a pas de solution.

La courbe de \(f\) reste toujours strictement entre les droites \(y=-2\) (minorant) et \(y=3\) (majorant), sans jamais les atteindre.

Exercice 3 — Étude de fonctions

6,5 pts

On considère les fonctions \(f\) et \(g\) définies par : \(f(x) = \dfrac{1}{3}x^3\), \(\quad g(x) = \sqrt{x+2}\).

Type : Domaine, variations & tracé

1) a - Déterminer \(D_f\), et le tableau de variation de \(f\).

b - Déterminer \(D_g\), et le tableau de variation de \(g\).

c - Tracer \(C_f\) et \(C_g\) leurs courbes respectives dans le même repère orthonormé \((O; \vec{i}; \vec{j})\).

✅ Correction

a) Fonction \(f\)

Domaine :

\(f(x) = \frac{1}{3}x^3\) est une fonction polynomiale, donc définie sur \(\mathbb{R}\).

Conclusion

\(\boxed{D_f = \mathbb{R}}\)

Variations de \(f\) :

\(f'(x) = x^2 \ge 0\) pour tout \(x \in \mathbb{R}\), avec \(f'(0)=0\). Donc \(f\) est croissante sur \(\mathbb{R}\).

$x$$-\infty$$0$$+\infty$
$f$$-\infty$↗$0$↗$+\infty$

b) Fonction \(g\)

Domaine :

\(g(x)=\sqrt{x+2}\) définie pour \(x+2 \ge 0 \iff x \ge -2\).

Conclusion

\(\boxed{D_g = [-2, +\infty[}\)

Variations de \(g\) :

La fonction racine carrée est croissante sur son domaine. Donc \(g\) est croissante sur \([-2,+\infty[\).

$x$$-2$$+\infty$
$g$$0$↗$+\infty$

c) Tracé des courbes

\((C_f)\) en rouge (cubique), \((C_g)\) en jaune (racine carrée).

Type : Encadrement & résolution graphique

2) On considère l'équation \(E : x^3-3\sqrt{x+2}=0\).

a – Montrer que : \(E \Leftrightarrow f(x)=g(x)\), et déduire graphiquement que \(E\) admet une solution unique \(\alpha\) dans \([-2;+\infty[\).

b – Montrer que : \(1 < \alpha < 2\).

c – Résoudre graphiquement dans \([-2;+\infty[\), l'inéquation \(F : x^3-3\sqrt{x+2} > 0\).

✅ Correction

a) Équivalence et solution unique

Équivalence :
\[ x^3-3\sqrt{x+2}=0 \iff \frac{1}{3}x^3 = \sqrt{x+2} \iff f(x)=g(x) \]
Solution unique :

Graphiquement, \((C_f)\) et \((C_g)\) se coupent en un seul point sur \([-2,+\infty[\).

Donc \(E\) admet une solution unique \(\alpha \in [-2,+\infty[\).

b) Encadrement de \(\alpha\)

Vérification :

On pose \(h(x)=f(x)-g(x)=\frac{1}{3}x^3-\sqrt{x+2}\).

\[ h(1) = \frac{1}{3} - \sqrt{3} \approx 0{,}33 - 1{,}73 = -1{,}40 < 0 \]
\[ h(2) = \frac{8}{3} - \sqrt{4} \approx 2{,}67 - 2 = 0{,}67 > 0 \]

Comme \(h\) est continue et strictement croissante sur \([-2,+\infty[\) (car \(f\) et \(g\) sont croissantes), il existe une unique racine \(\alpha\) dans \([1,2]\).

Conclusion

\(\boxed{1 < \alpha < 2}\)

c) Résolution graphique de l'inéquation

Inéquation :
\[ x^3-3\sqrt{x+2} > 0 \iff \frac{1}{3}x^3 > \sqrt{x+2} \iff f(x) > g(x) \]

Graphiquement, \(f(x)>g(x)\) lorsque \((C_f)\) est au-dessus de \((C_g)\).

Zone où \((C_f)\) est au-dessus de \((C_g)\).

Conclusion

\(\boxed{S = ]\alpha, +\infty[}\) où \(\alpha \in ]1,2[\) est la solution de \(E\).
