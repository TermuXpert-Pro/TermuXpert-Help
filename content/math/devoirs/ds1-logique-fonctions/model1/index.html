Exercice 1

9 pts · 1,5 pt × 6
1)

$P_1 : (\forall x \in \mathbb{R}^{*+}) \; ; \; x + \dfrac{16}{x} > 8$

✅ Correction

$P_1$ est fausse.

Raisonnement : On raisonne par contre-exemple. Pour $x=4 \in \mathbb{R}^{*+}$, on a :
$$x+\dfrac{16}{x}=4+\dfrac{16}{4}=8 \not> 8$$

Minimum de $x+\frac{16}{x}$ égal à 8, atteint en $x=4$.

Négation

$\overline{P_1} : \exists x \in \mathbb{R}^{*+} \; ; \; x+\dfrac{16}{x} \le 8$ (vraie)

2)

$P_2 : \forall n \in \mathbb{N} \; : \; \dfrac{n+5}{n+4} \neq 1$

✅ Correction

$P_2$ est vraie.

Raisonnement par l'absurde : Supposons qu'il existe $n \in \mathbb{N}$ tel que $\dfrac{n+5}{n+4}=1$. Alors :
$$n+5 = n+4 \iff 5=4 \quad \text{(absurde)}$$
Conclusion

$\forall n \in \mathbb{N}, \dfrac{n+5}{n+4} \neq 1$.

Négation

$\overline{P_2} : \exists n \in \mathbb{N} \; ; \; \dfrac{n+5}{n+4} = 1$ (fausse)

3)

$P_3 : \forall x \in \mathbb{R}^{*} \; ; \; \forall y \in \mathbb{R}^{*} \; : \; x \neq y \Rightarrow \dfrac{x}{5+x} \neq \dfrac{y}{5+y}$

✅ Correction

$P_3$ est vraie.

Raisonnement par contraposée : Montrons que $\dfrac{x}{5+x}=\dfrac{y}{5+y} \Rightarrow x=y$.
$$\dfrac{x}{5+x}=\dfrac{y}{5+y} \iff x(5+y)=y(5+x) \iff 5x=5y \iff x=y$$
Conclusion

L'implication est vraie pour tous $x, y \in \mathbb{R}^{*}$.

Négation

$\overline{P_3} : \exists x,y \in \mathbb{R}^{*} \; ; \; x\neq y \text{ et } \dfrac{x}{5+x}=\dfrac{y}{5+y}$ (fausse)

4)

$P_4 : (\forall n \in \mathbb{N}) \; ; \; n^2+3n+2023 \text{ est un entier impair}$

✅ Correction

$P_4$ est vraie.

Raisonnement : On a $n^2+3n = n(n+3)$.
  • Si $n$ est pair : $n(n+3)$ = pair × impair = pair.
  • Si $n$ est impair : $n(n+3)$ = impair × pair = pair.
Conclusion : Dans tous les cas, $n^2+3n$ est pair. Donc $n^2+3n+2023$ = pair + impair = impair.
Conclusion

$\forall n \in \mathbb{N}, n^2+3n+2023$ est impair.

5)

$P_5 : \forall x \in \mathbb{R} \; ; \; \forall y \in \mathbb{R} \; \; (x+3)(y-3) = (x-3)(y+3) \Rightarrow x = y$

✅ Correction

$P_5$ est vraie.

Développement :
$$(x+3)(y-3)=(x-3)(y+3) \iff -3x+3y=3x-3y \iff 6y=6x \iff x=y$$
Conclusion

L'implication est vraie pour tous $x, y \in \mathbb{R}$.

6)

$P_6 : \forall n \in \mathbb{N} \; ; \; n^3 - n \text{ est divisible par } 3$

✅ Correction

$P_6$ est vraie.

Factorisation :
$$n^3 - n = n(n^2-1) = n(n-1)(n+1)$$
Raisonnement : $n(n-1)(n+1)$ est le produit de trois entiers consécutifs. Parmi trois entiers consécutifs, l'un d'eux est toujours divisible par 3.

Parmi $n-1$, $n$ et $n+1$, l'un des trois est toujours un multiple de 3.

Conclusion

$\forall n \in \mathbb{N}, n^3-n$ est divisible par 3.

Exercice 2

11 pts
1)

Vérifier que $(C_f)$ et $(C_g)$ se coupent en $A(2\,;1)$. (0,5 pt)

✅ Correction
Calcul de $f(2)$ :
$$f(2) = -2^2 + 2(2) + 1 = -4+4+1 = 1$$
Calcul de $g(2)$ :
$$g(2) = \sqrt{2-1} = \sqrt{1} = 1$$
Conclusion

Puisque $f(2) = g(2) = 1$, le point $A(2,1)$ appartient aux deux courbes.

2)

Déterminer les tableaux de variations de $f$ et $g$. (1,5 pt)

✅ Correction

Variations de $f$ :

Forme canonique :
$$f(x) = -(x-1)^2 + 2$$

Le sommet de la parabole est en $x=1$, avec $f(1)=2$.

$x$$-\infty$$1$$+\infty$
$f$$-\infty$↗$2$↘$-\infty$

Variations de $g$ :

Domaine et monotonie :

$D_g = [1, +\infty[$. La fonction racine carrée est croissante sur son domaine.

$x$$1$$+\infty$
$g$$0$↗$+\infty$
3)

Tracer les courbes $(C_f)$ et $(C_g)$ dans un même repère $(O,\vec{i},\vec{j})$. (2 pts)

✅ Correction

$(C_f)$ en rouge, $(C_g)$ en jaune. Le point d'intersection $A(2,1)$ est indiqué en turquoise.

4)

Résoudre graphiquement l'inéquation $x^2-2x-1+\sqrt{x-1} < 0$. (2 pts)

✅ Correction
Transformation :
$$x^2-2x-1+\sqrt{x-1} < 0 \iff g(x) < f(x)$$
Lecture graphique : $(C_g)$ est en dessous de $(C_f)$ sur $[1, 2[$.

Zone où $(C_g)$ est en dessous de $(C_f)$.

Solution

$\boxed{S = [1, 2[}$

5)

Déterminer graphiquement les images de $[0\,;1]$ et $[1\,;2]$ par $f$. (1 pt)

✅ Correction
Image de $[0, 1]$ : $f$ est croissante sur cet intervalle.
$$f([0,1]) = [f(0), f(1)] = [1, 2]$$
Image de $[1, 2]$ : $f$ est décroissante sur cet intervalle.
$$f([1,2]) = [f(2), f(1)] = [1, 2]$$

Les deux intervalles $[0,1]$ et $[1,2]$ ont exactement la même image $[1,2]$ par $f$.

Conclusion

$f([0,1]) = f([1,2]) = [1, 2]$

6)

On considère la fonction $h$ telle que : $h(x)=\sqrt{-x^2+2x}$

a) Déterminer $D_h$. (1 pt)

b) Vérifier que $h(x)=(g\circ f)(x) \; \forall x\in D_h$. (1 pt)

c) Étudier la monotonie de $h$ dans $[0\,;1]$ et $[1\,;2]$. (2 pts)

✅ Correction

a) Domaine de $h$

Condition d'existence :
$$-x^2+2x \ge 0 \iff x(x-2) \le 0 \iff x \in [0, 2]$$
Conclusion

$\boxed{D_h = [0, 2]}$

b) Vérification de $h = g \circ f$

Calcul : Pour $x \in D_h = [0,2]$, on a $f(x) \in [1,2] \subset D_g$.
$$(g \circ f)(x) = g(f(x)) = \sqrt{f(x)-1} = \sqrt{-x^2+2x+1-1} = \sqrt{-x^2+2x} = h(x)$$
Conclusion

$\boxed{h = g \circ f}$

c) Monotonie de $h$

Raisonnement : $h = g \circ f$, avec $g$ croissante sur $[1, +\infty[$.
  • Sur $[0, 1]$ : $f$ est croissante $\Rightarrow$ (croissante ∘ croissante) $\Rightarrow$ $h$ est croissante.
  • Sur $[1, 2]$ : $f$ est décroissante $\Rightarrow$ (croissante ∘ décroissante) $\Rightarrow$ $h$ est décroissante.

$h$ est le demi-cercle supérieur de centre $(1;0)$ et de rayon 1.

Conclusion

$h$ est croissante sur $[0,1]$ et décroissante sur $[1,2]$.
