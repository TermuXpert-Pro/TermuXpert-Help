Expression algébrique

Une expression algébrique (ou littérale) est une expression qui contient une ou plusieurs lettres (inconnues), appelées variables.
Pour réduire une expression, on regroupe les termes qui contiennent la même lettre au même degré (termes semblables).
Ex

$A = 3x + 5 - x + 2$ est une expression algébrique de variable $x$

Développer une expression

Développer, c'est transformer un produit en une somme, en utilisant la distributivité.
$k(a + b) = ka + kb$
$(a + b)(c + d) = ac + ad + bc + bd$
Ex

$3(x + 4) = 3x + 12$   ·   $(x+2)(x+5) = x^2 + 5x + 2x + 10$

Identités remarquables

Trois formules à connaître par cœur, pour développer plus vite.
$(a+b)^2$$= a^2 + 2ab + b^2$
$(a-b)^2$$= a^2 - 2ab + b^2$
$(a+b)(a-b)$$= a^2 - b^2$
Ex

$(x+3)^2 = x^2 + 6x + 9$   ·   $(x-2)^2 = x^2 - 4x + 4$   ·   $(x+5)(x-5) = x^2 - 25$

Factoriser une expression

Factoriser, c'est transformer une somme en un produit : mettre un facteur commun en évidence, ou utiliser une identité remarquable en sens inverse.
$ka + kb = k(a+b)$
$a^2 + 2ab + b^2$$= (a+b)^2$
$a^2 - 2ab + b^2$$= (a-b)^2$
$a^2 - b^2$$= (a+b)(a-b)$
Ex

$3x + 3\times5 = 3(x+5)$   ·   $x^2 - 16 = (x+4)(x-4)$

Erreurs fréquentes

Attention à ces confusions classiques :
$(a+b)^2 \neq a^2 + b^2$  ·  $(a+b)^2 = a^2 + 2ab + b^2$
$(a-b)^2 \neq a^2 - b^2$  ·  $(a-b)^2 = a^2 - 2ab + b^2$
$-3(x-2) \neq -3x - 6$  ·  $-3(x-2) = -3x + 6$

Exercices

1.
Développer et réduire $A = 4(x+2) - 3x$
✅ Solution
Étape 1 — $A = 4x + 8 - 3x$
Étape 2 — réduire : $4x - 3x = x$

$A = x + 8$

2.
Développer $B = (x+4)(x-3)$
✅ Solution
Étape 1 — $B = x^2 - 3x + 4x - 12$
Étape 2 — réduire : $-3x + 4x = x$

$B = x^2 + x - 12$

3.
Développer $C = (3x - 2)^2$ à l'aide d'une identité remarquable
✅ Solution
Étape 1 — $a = 3x$ , $b = 2$ , utiliser $(a-b)^2 = a^2 - 2ab + b^2$
Étape 2 — $(3x)^2 - 2\times3x\times2 + 2^2 = 9x^2 - 12x + 4$

$C = 9x^2 - 12x + 4$

4.
Factoriser $D = 7x + 7\times3$
✅ Solution
Étape 1 — $7$ est un facteur commun à $x$ et $3$
Étape 2 — mettre $7$ en facteur : $7(x+3)$

$D = 7(x+3)$

5.
Factoriser $E = x^2 - 49$
✅ Solution
Étape 1 — reconnaître une différence de carrés : $x^2 - 7^2$
Étape 2 — appliquer $a^2 - b^2 = (a+b)(a-b)$

$E = (x+7)(x-7)$
