Comparaison

$a > 0 > b$
$a, b > 0$$a > b$
$a, b < 0$$a > b \Leftrightarrow |a| < |b|$
Ex

$-3 > -8$   ·   $5 > -10$   ·   $-1 > -2{,}5$

Exemple résolu — Comparer $-6$ et $-4$
On a : deux nombres négatifs $\Rightarrow$ on compare $|-6|$ et $|-4|$
Alors : $|-6| = 6$  ,  $|-4| = 4$
D'où : $6 > 4$ $\Rightarrow$ le nombre à plus grande valeur absolue est le plus petit
$-6 < -4$

Addition

même signe$|a| + |b|$, garder le signe
signes différents$|a| - |b|$, signe du plus grand
Ex

$(-5)+(-3) = -8$   ·   $(-7)+4 = -3$   ·   $6+(-2) = 4$

Exemple résolu — Calculer $(-9) + 4$
On a : signes différents $\Rightarrow$ $|-9| = 9$  ,  $|4| = 4$
Donc : $9 - 4 = 5$
D'où : le signe du plus grand $(-9)$ est « − » $\Rightarrow$ résultat négatif
$(-9) + 4 = -5$

Soustraction

L'opposé de $a$ est noté $-a$, tel que $a + (-a) = 0$
$a - b = a + (-b)$
Ex

$(-4)-(-9) = (-4)+9 = 5$   ·   $3-8 = 3+(-8) = -5$

Exemple résolu — Calculer $(-6) - (-2)$
On a : soustraire $(-2)$ = additionner son opposé $(+2)$
Donc : $(-6) - (-2) = (-6) + 2$
D'où : signes différents $\Rightarrow$ $|-6| = 6$, $|2| = 2$ $\Rightarrow$ $6 - 2 = 4$, signe de $-6$
$(-6) - (-2) = -4$

Multiplication / Division

SignesRésultat
$+ \cdot +$  /  $- \cdot -$+
$+ \cdot -$  /  $- \cdot +$−
Ex

$(-4)\times(-3) = 12$   ·   $(-15)\div 3 = -5$   ·   $(-20)\div(-4) = 5$

Exemple résolu — Calculer $(-7) \times (-2) \times 3$
On a : $(-7) \times (-2)$ : mêmes signes $\Rightarrow$ résultat positif
Donc : $(-7) \times (-2) = 14$
D'où : $14 \times 3 = 42$
$(-7) \times (-2) \times 3 = 42$

Priorités opératoires

( )   →   puissances   →   $\times\;\div$   →   $+\;-$
Exemple résolu — Calculer $5 + 3 \times (-4)$
On a : pas de parenthèses à calculer, pas de puissance
Alors : la multiplication est prioritaire : $3 \times (-4) = -12$
D'où : il reste $5 + (-12)$
$5 + 3 \times (-4) = -7$

Exercices

1.
$A = (-12) + 7 - (-5)$
✅ Solution
On a : $A = (-12) + 7 - (-5)$
On transforme la soustraction : $A = (-12) + 7 + 5$
Donc : $(-12) + 7$ : signes différents $\Rightarrow |-12|=12$, $|7|=7 \Rightarrow 12-7=5$, signe de $-12$
Alors : $(-12) + 7 = -5$
D'où : $A = (-5) + 5 = 0$

$A = 0$

2.
$B = (-6) \times (-3) - 4 \times 2$
✅ Solution
On a : $B = (-6) \times (-3) - 4 \times 2$
Priorité aux multiplications : $(-6) \times (-3) = 18$
Et : $4 \times 2 = 8$
Donc : $B = 18 - 8$
D'où : $B = 10$

$B = 10$

3.
Comparer $C = -7$ et $D = -2{,}5$
✅ Solution
On a : $C$ et $D$ sont négatifs $\Rightarrow$ on compare $|C|$ et $|D|$
Alors : $|C| = 7$  ,  $|D| = 2{,}5$
Puisque : $7 > 2{,}5$, et entre deux négatifs, celui de plus grande valeur absolue est le plus petit
D'où : $C < D$

$C < D$  ($-7 < -2{,}5$)

4.
$E = (-18) \div (-6) + (-5) \times 2$
✅ Solution
On a : $E = (-18) \div (-6) + (-5) \times 2$
Priorité à la division et à la multiplication :
On a : $(-18) \div (-6) = 3$ (mêmes signes)
Et : $(-5) \times 2 = -10$ (signes différents)
Donc : $E = 3 + (-10)$
D'où : $E = -7$

$E = -7$

5.
$F = -3^2 + (-2)^3$
✅ Solution
On a : $F = -3^2 + (-2)^3$
Puisque : seul 3 est élevé au carré $\Rightarrow -3^2 = -9$
Et : $(-2)^3 = (-2)\times(-2)\times(-2) = -8$
Donc : $F = -9 + (-8)$
D'où : $F = -17$

$F = -17$
