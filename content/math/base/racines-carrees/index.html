Définition

Pour $a \ge 0$, $\sqrt{a}$ est le nombre positif dont le carré est $a$.
$\left(\sqrt{a}\right)^2$$= a$  ($a \ge 0$)
$\sqrt{a^2}$$= |a|$  (pour tout $a$)
$\sqrt{0}$ , $\sqrt{1}$$= 0$ , $= 1$
Ex

$\sqrt{9} = 3$   ·   $\left(\sqrt{7}\right)^2 = 7$   ·   $\sqrt{(-5)^2} = 5$

Exemple résolu — Calculer $\sqrt{64}$
On a : on cherche le nombre positif dont le carré est $64$
D'où : $8^2 = 64$
$\sqrt{64} = 8$

Propriétés (produit / quotient)

Produit$\sqrt{a\times b} = \sqrt{a}\times\sqrt{b}$  ($a,b \ge 0$)
Quotient$\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}$  ($a \ge 0$, $b > 0$)
Ex

$\sqrt{4\times9} = \sqrt{4}\times\sqrt{9} = 2\times3 = 6$   ·   $\sqrt{\dfrac{16}{4}} = \dfrac{\sqrt{16}}{\sqrt{4}} = \dfrac{4}{2} = 2$

Exemple résolu — Calculer $\sqrt{25\times16}$
On a : $\sqrt{25\times16} = \sqrt{25}\times\sqrt{16}$
D'où : $\sqrt{25} = 5$  ,  $\sqrt{16} = 4$
$\sqrt{25\times16} = 20$

Simplification

Factoriser le radicande en (carré parfait) $\times$ (facteur restant)
$\sqrt{a^2 \times b} = a\sqrt{b}$  ($a \ge 0$, $b \ge 0$)
Ex

$\sqrt{12} = \sqrt{4\times3} = 2\sqrt{3}$   ·   $\sqrt{50} = \sqrt{25\times2} = 5\sqrt{2}$

Exemple résolu — Simplifier $\sqrt{72}$
On a : on cherche le plus grand carré parfait qui divise $72$ : $36$
Donc : $72 = 36\times2$
D'où : $\sqrt{72} = \sqrt{36}\times\sqrt{2} = 6\sqrt{2}$
$\sqrt{72} = 6\sqrt{2}$

Addition / Soustraction

On ne peut additionner (ou soustraire) que des racines ayant le même radicande, en simplifiant d'abord si besoin.
$a\sqrt{c} \pm b\sqrt{c} = (a \pm b)\sqrt{c}$
Ex

$3\sqrt{5} + 2\sqrt{5} = 5\sqrt{5}$   ·   $7\sqrt{2} - 4\sqrt{2} = 3\sqrt{2}$

Exemple résolu — Calculer $\sqrt{8} + \sqrt{18}$
On a : on simplifie chaque racine : $\sqrt{8} = 2\sqrt{2}$  ,  $\sqrt{18} = 3\sqrt{2}$
D'où : même radicande $\sqrt{2}$ $\Rightarrow$ on additionne : $2\sqrt{2} + 3\sqrt{2}$
$\sqrt{8} + \sqrt{18} = 5\sqrt{2}$

Rendre rationnel un dénominateur

Multiplier le numérateur et le dénominateur par la même racine, pour faire disparaître la racine du dénominateur.
$\dfrac{a}{\sqrt{b}} = \dfrac{a\sqrt{b}}{\sqrt{b}\times\sqrt{b}} = \dfrac{a\sqrt{b}}{b}$  ($b > 0$)
Ex

$\dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}$   ·   $\dfrac{6}{\sqrt{3}} = \dfrac{6\sqrt{3}}{3} = 2\sqrt{3}$

Exemple résolu — Rendre rationnel $\dfrac{5}{\sqrt{5}}$
On a : on multiplie haut et bas par $\sqrt{5}$ : $\dfrac{5\sqrt{5}}{\sqrt{5}\times\sqrt{5}}$
Donc : $\sqrt{5}\times\sqrt{5} = 5$
D'où : $\dfrac{5\sqrt{5}}{5}$, on simplifie par $5$
$\dfrac{5}{\sqrt{5}} = \sqrt{5}$

Exercices

1.
Simplifier $A = \sqrt{45}$
✅ Solution
On a : $45 = 9\times5$
D'où : $\sqrt{45} = \sqrt{9}\times\sqrt{5} = 3\sqrt{5}$

$A = 3\sqrt{5}$

2.
$B = \sqrt{27} + \sqrt{12}$
✅ Solution
On a : $\sqrt{27} = 3\sqrt{3}$  ,  $\sqrt{12} = 2\sqrt{3}$
D'où : même radicande $\Rightarrow$ $3\sqrt{3} + 2\sqrt{3}$

$B = 5\sqrt{3}$

3.
$C = \sqrt{5}\times\sqrt{20}$
✅ Solution
On a : $C = \sqrt{5\times20} = \sqrt{100}$
D'où : $\sqrt{100} = 10$

$C = 10$

4.
Rendre rationnel $D = \dfrac{3}{\sqrt{6}}$
✅ Solution
On a : on multiplie haut et bas par $\sqrt{6}$ : $\dfrac{3\sqrt{6}}{6}$
D'où : on simplifie par $3$

$D = \dfrac{\sqrt{6}}{2}$

5.
$E = \sqrt{75} - \sqrt{27} + \sqrt{3}$
✅ Solution
On a : $\sqrt{75} = 5\sqrt{3}$  ,  $\sqrt{27} = 3\sqrt{3}$
D'où : $E = 5\sqrt{3} - 3\sqrt{3} + \sqrt{3}$

$E = 3\sqrt{3}$
