Fonction linéaire

Une fonction linéaire est une fonction $f$ définie par $f(x) = ax$, où $a$ est un nombre réel appelé coefficient.
$f(x) = ax$
Sa représentation graphique est une droite qui passe par l'origine $O(0\,;\,0)$.
Ex

$f(x) = 3x$   ·   $g(x) = -2x$

Exemple résolu — Soit $f(x) = 4x$. Calculer $f(2)$
On a : on remplace $x$ par $2$ : $f(2) = 4\times2$
D'où : $f(2) = 8$
$f(2) = 8$  → la droite passe par le point $(2\,;\,8)$

Fonction affine

Une fonction affine est une fonction $f$ définie par $f(x) = ax + b$, où $a$ et $b$ sont des nombres réels.
$f(x) = ax + b$
$a$coefficient directeur (pente de la droite)
$b$ordonnée à l'origine (la droite coupe l'axe $(Oy)$ en $(0\,;\,b)$)
Une fonction linéaire est un cas particulier de fonction affine, avec $b = 0$.
Ex

$f(x) = 2x + 3$  : $a = 2$, $b = 3$

Exemple résolu — Soit $f(x) = -3x + 5$. Calculer $f(-1)$
On a : on remplace $x$ par $-1$ : $f(-1) = -3\times(-1) + 5$
D'où : $= 3 + 5$
$f(-1) = 8$

Déterminer le coefficient directeur

Connaissant deux points $A(x_A\,;\,y_A)$ et $B(x_B\,;\,y_B)$ de la droite, on calcule $a$ par :
$a = \dfrac{y_B - y_A}{x_B - x_A}$
Une fois $a$ connu, on trouve $b$ en remplaçant les coordonnées d'un point dans $y = ax + b$.
Ex

$A(1\,;\,4)$ et $B(3\,;\,10)$  →  $a = \dfrac{10-4}{3-1} = 3$

Exemple résolu — Trouver $f$ affine telle que $A(1\,;\,5)$ et $B(3\,;\,9)$
On a : $a = \dfrac{9-5}{3-1} = \dfrac{4}{2} = 2$
Donc : on utilise $A(1\,;\,5)$ : $5 = 2\times1 + b$
D'où : $b = 5 - 2 = 3$
$f(x) = 2x + 3$

Sens de variation

Le signe de $a$ détermine si la fonction est croissante ou décroissante.
$a > 0$$f$ est croissante (la droite « monte »)
$a < 0$$f$ est décroissante (la droite « descend »)
$a = 0$$f$ est constante (droite horizontale)
Ex

$f(x) = 2x - 1$ est croissante   ·   $g(x) = -5x + 2$ est décroissante

Exemple résolu — Étudier le sens de variation de $f(x) = -4x + 7$
On a : $a = -4$
D'où : $a < 0$ $\Rightarrow$ $f$ est décroissante
$f$ est décroissante sur $\mathbb{R}$

Erreurs fréquentes

Attention à ces confusions classiques :
confondre $a$ et $b$  ·  $a$ = coefficient directeur, $b$ = ordonnée à l'origine
$a = \dfrac{y_A - y_B}{x_B - x_A}$  ·  $a = \dfrac{y_B - y_A}{x_B - x_A}$ (même ordre au numérateur et dénominateur)
croire qu'une fonction linéaire ne passe pas par $O$  ·  toute fonction linéaire passe par $O(0\,;\,0)$

Exercices

1.
Soit $f(x) = -2x + 6$. Calculer $f(0)$ et $f(3)$
✅ Solution
On a : $f(0) = -2\times0 + 6 = 6$
D'où : $f(3) = -2\times3 + 6 = 0$

$f(0) = 6$  ,  $f(3) = 0$

2.
Déterminer si $f(x) = 5x - 2$ est croissante ou décroissante
✅ Solution
On a : $a = 5$
D'où : $a > 0 \Rightarrow f$ est croissante

$f$ est croissante

3.
Calculer le coefficient directeur de la droite passant par $A(2\,;\,1)$ et $B(5\,;\,7)$
✅ Solution
On a : $a = \dfrac{7-1}{5-2}$
D'où : $a = \dfrac{6}{3} = 2$

$a = 2$

4.
Déterminer $f$ affine sachant que $f(0) = 4$ et $f(2) = 10$
✅ Solution
On a : $f(0) = 4 \Rightarrow b = 4$
D'où : $a = \dfrac{10-4}{2-0} = 3$

$f(x) = 3x + 4$

5.
La droite $(D)$ passe par $A(-1\,;\,3)$ et $B(1\,;\,-1)$. Trouver son équation
✅ Solution
On a : $a = \dfrac{-1-3}{1-(-1)} = \dfrac{-4}{2} = -2$
D'où : on utilise $B(1\,;\,-1)$ : $-1 = -2\times1 + b \Rightarrow b = 1$

$(D): y = -2x + 1$
