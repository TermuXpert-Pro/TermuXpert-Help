Partie 5 : Étude des fonctions de référence

1 Fonction du second degré : $f(x) = ax^2 + bx + c$

Forme canonique :

$$f(x) = a\left(x + \frac{b}{2a}\right)^2 + f\left(-\frac{b}{2a}\right)$$

avec $\displaystyle f\left(-\frac{b}{2a}\right) = -\frac{\Delta}{4a}$

Cas $a > 0$

Parabole orientée vers le haut.

$$f(x) - f\left(-\frac{b}{2a}\right) = a\left(x + \frac{b}{2a}\right)^2 \ge 0$$

Minimum absolu : $\displaystyle f\left(-\frac{b}{2a}\right)$

$x$$-\infty$$-\frac{b}{2a}$$+\infty$
$f(x)$↘$f(-\frac{b}{2a})$↗

📈 Parabole $a > 0$

Parabole orientée vers le haut

Cas $a < 0$

Parabole orientée vers le bas.

$$f(x) - f\left(-\frac{b}{2a}\right) = a\left(x + \frac{b}{2a}\right)^2 \le 0$$

Maximum absolu : $\displaystyle f\left(-\frac{b}{2a}\right)$

$x$$-\infty$$-\frac{b}{2a}$$+\infty$
$f(x)$↗$f(-\frac{b}{2a})$↘

📈 Parabole $a < 0$

Parabole orientée vers le bas

Vocabulaire
  • La courbe s'appelle une parabole.
  • Sommet : $\displaystyle S\left(-\frac{b}{2a}, f\left(-\frac{b}{2a}\right)\right)$
  • Axe de symétrie : $\displaystyle x = -\frac{b}{2a}$
Résumé
  • $a > 0$ : parabole vers le haut, minimum.
  • $a < 0$ : parabole vers le bas, maximum.
  • Sommet $\displaystyle S\left(-\frac{b}{2a}, f\left(-\frac{b}{2a}\right)\right)$

2 Fonction cube : $f(x) = ax^3$

  • $D_f = \mathbb{R}$
  • $f$ est impaire : $f(-x) = -f(x)$
  • Ensemble d'étude : $D_E = \mathbb{R}^+$
Cas $a > 0$

$f$ est strictement croissante sur $\mathbb{R}$.

$$x < x' \Rightarrow ax^3 < a(x')^3 \Rightarrow f(x) < f(x')$$

📈 Fonction cube $a > 0$

$f(x) = x^3$

Cas $a < 0$

$f$ est strictement décroissante sur $\mathbb{R}$.

$$x < x' \Rightarrow ax^3 > a(x')^3 \Rightarrow f(x) > f(x')$$

📈 Fonction cube $a < 0$

$f(x) = -x^3$

Applications :

1. $f(x) = \frac{1}{2}x^3$ : $a = \frac{1}{2} > 0$ → $f$ est strictement croissante sur $\mathbb{R}$.
2. $f(x) = -\frac{2}{3}x^3$ : $a = -\frac{2}{3} < 0$ → $f$ est strictement décroissante sur $\mathbb{R}$.
Résumé
  • Fonction impaire : $f(-x) = -f(x)$.
  • $a > 0$ : croissante.
  • $a < 0$ : décroissante.

3 Fonction homographique : $f(x) = \frac{ax+b}{cx+d}$

Définition

$c \neq 0$ et $\Delta = ad - bc$

$$D_f = \mathbb{R} \setminus \left\{-\frac{d}{c}\right\}$$

Taux d'accroissement :

$$T_f = \frac{\Delta}{(cx+d)(cx'+d)}$$

Le signe de $T_f$ est celui de $\Delta$.

Cas $\Delta > 0$

$f$ est strictement croissante sur $]-\infty, -\frac{d}{c}[$ et $]-\frac{d}{c}, +\infty[$.

Cas $\Delta < 0$

$f$ est strictement décroissante sur $]-\infty, -\frac{d}{c}[$ et $]-\frac{d}{c}, +\infty[$.

Vocabulaire
  • La courbe est une hyperbole.
  • Centre de symétrie : $\displaystyle \Omega\left(-\frac{d}{c}, \frac{a}{c}\right)$
  • Asymptote verticale : $\displaystyle x = -\frac{d}{c}$
  • Asymptote horizontale : $\displaystyle y = \frac{a}{c}$

📈 Hyperbole

$f(x) = \frac{2x+1}{x+1}$ avec asymptotes $x = -1$ et $y = 2$

Application : $f(x) = \frac{2x+1}{x+1}$

Étape 1 : $\Delta = 2 \times 1 - 1 \times 1 = 1 > 0$
Étape 2 : $D_f = \mathbb{R} \setminus \{-1\}$
Étape 3 : Asymptote verticale : $x = -1$
Étape 4 : Asymptote horizontale : $y = 2$
Étape 5 : Centre de symétrie : $\Omega(-1, 2)$

Conclusion : Hyperbole avec $f$ strictement croissante sur chaque intervalle.

Résumé
  • $\Delta > 0$ : croissante.
  • $\Delta < 0$ : décroissante.
  • Asymptotes : $x = -\frac{d}{c}$ et $y = \frac{a}{c}$.

4 Fonction racine carrée

Cas $f(x) = \sqrt{x+a}$
  • $D_f = [-a, +\infty[$
  • $f$ est strictement croissante sur $D_f$.
$$x < x' \Rightarrow \sqrt{x+a} < \sqrt{x'+a} \Rightarrow f(x) < f(x')$$

📈 $f(x) = \sqrt{x}$

Fonction racine carrée

Cas $f(x) = \sqrt{a-x}$
  • $D_f = ]-\infty, a]$
  • $f$ est strictement décroissante sur $D_f$.
$$x < x' \Rightarrow \sqrt{a-x} > \sqrt{a-x'} \Rightarrow f(x) > f(x')$$

📈 $f(x) = \sqrt{1-x}$

Fonction racine carrée décroissante

Résumé
  • $\sqrt{x+a}$ : croissante sur $[-a, +\infty[$.
  • $\sqrt{a-x}$ : décroissante sur $]-\infty, a]$.
