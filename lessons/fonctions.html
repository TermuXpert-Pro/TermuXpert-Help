Généralités sur les fonctions

1 Rappels

A. Fonction numérique

Définition

Une fonction numérique $f$ est une relation qui associe à chaque élément $x$ de $\mathbb{R}$ au plus un élément $y$ de $\mathbb{R}$.

$$f : \mathbb{R} \to \mathbb{R}$$

$$x \mapsto f(x)$$

Ensemble de définition : $D_f$ ou $D$.

Tous les éléments $x$ de $\mathbb{R}$ qui ont une image par $f$.

B. Fonction paire - Fonction impaire

Définition

$f$ est une fonction définie sur $D_f$.

Fonction paire :

$$f \text{ est paire sur } D_f \Leftrightarrow \begin{cases} \forall x \in D_f, -x \in D_f \\ \forall x \in D_f, f(-x) = f(x) \end{cases}$$

Fonction impaire :

$$f \text{ est impaire sur } D_f \Leftrightarrow \begin{cases} \forall x \in D_f, -x \in D_f \\ \forall x \in D_f, f(-x) = -f(x) \end{cases}$$
Résumé
  • Paire : $f(-x) = f(x)$ → courbe symétrique par rapport à l'axe des ordonnées.
  • Impaire : $f(-x) = -f(x)$ → courbe symétrique par rapport à l'origine.

2 Monotonie d'une fonction

Définition

$f$ est une fonction définie sur un intervalle $I$.

Fonction croissante :

$$\forall x,x' \in I : x < x' \Rightarrow f(x) \le f(x')$$

Fonction décroissante :

$$\forall x,x' \in I : x < x' \Rightarrow f(x) \ge f(x')$$

Fonction constante :

$$\forall x,x' \in I : f(x) = f(x')$$
Rappel
  • Croissante : l'inégalité ne change pas de sens.
  • Décroissante : l'inégalité change de sens.

Extrémums d'une fonction

Définition

$f$ définie sur $D_f$ et $x_0 \in D_f$.

Maximum absolu :

$$\forall x \in D_f : f(x) \le f(x_0)$$

Minimum absolu :

$$\forall x \in D_f : f(x_0) \le f(x)$$

Extrémums relatifs

Maximum relatif :

Il existe un intervalle ouvert $I_{x_0}$ tel que :

$$\forall x \in I_{x_0} : f(x) \le f(x_0)$$

Minimum relatif :

Il existe un intervalle ouvert $I_{x_0}$ tel que :

$$\forall x \in I_{x_0} : f(x_0) \le f(x)$$
Résumé
  • Absolu : sur tout $D_f$.
  • Relatif : sur un intervalle ouvert contenant $x_0$.

3 Fonction périodique

Définition

$f$ est périodique de période $T > 0$ sur $D_f$ ssi :

$$x \in D_f \Rightarrow (x+T \in D_f \text{ et } x-T \in D_f)$$

$$\forall x \in D_f : f(x+T) = f(x)$$

Remarque
  • $T$ est la plus petite période strictement positive.
  • $\sin x$ et $\cos x$ ont pour période $T = 2\pi$.
  • $\tan x$ a pour période $T = \pi$.

Exemple :

Montrer que $f(x) = \sin(ax)$ avec $a \neq 0$ est périodique de période $T = \frac{2\pi}{|a|}$.

4 Fonction majorée - minorée - bornée

Définitions

Majorée :

$$\exists M \in \mathbb{R} : \forall x \in I, f(x) \le M$$

Minorée :

$$\exists m \in \mathbb{R} : \forall x \in I, f(x) \ge m$$

Bornée :

$$f \text{ est majorée et minorée sur } I$$

Équivalent à :

$$\exists A \in \mathbb{R}^+ : \forall x \in I, |f(x)| \le A$$
Résumé
  • Majorée : il existe un nombre plus grand que toutes les valeurs.
  • Minorée : il existe un nombre plus petit que toutes les valeurs.
  • Bornée : les deux à la fois.

5 Fonctions de référence

A. Fonction du second degré : $f(x) = ax^2 + bx + c$

Cas $a > 0$

Parabole orientée vers le haut.

$$f(x) = a\left(x + \frac{b}{2a}\right)^2 + f\left(-\frac{b}{2a}\right)$$

Sommet : $S\left(-\frac{b}{2a}, f\left(-\frac{b}{2a}\right)\right)$

Axe de symétrie : $x = -\frac{b}{2a}$

$x$$-\infty$$-\frac{b}{2a}$$+\infty$
$f(x)$↘$f(-\frac{b}{2a})$↗
Cas $a < 0$

Parabole orientée vers le bas.

Sommet : $S\left(-\frac{b}{2a}, f\left(-\frac{b}{2a}\right)\right)$

Axe de symétrie : $x = -\frac{b}{2a}$

$x$$-\infty$$-\frac{b}{2a}$$+\infty$
$f(x)$↗$f(-\frac{b}{2a})$↘

Application : $f(x) = 2x^2 + 4x + 3$

Étape 1 : $a = 2 > 0$, $b = 4$, $c = 3$
Étape 2 : Sommet $S\left(-\frac{4}{2(2)}, f(-1)\right) = S(-1, 1)$
Étape 3 : Axe de symétrie : $x = -1$

Conclusion : Parabole orientée vers le haut, sommet $S(-1, 1)$.

Application : $f(x) = -x^2 + 4x$

Étape 1 : $a = -1 < 0$, $b = 4$, $c = 0$
Étape 2 : Sommet $S\left(-\frac{4}{2(-1)}, f(2)\right) = S(2, 4)$
Étape 3 : Axe de symétrie : $x = 2$

Conclusion : Parabole orientée vers le bas, sommet $S(2, 4)$.

B. Fonction cube : $f(x) = ax^3$

Cas $a > 0$ : $f$ est strictement croissante sur $\mathbb{R}$.

Cas $a < 0$ : $f$ est strictement décroissante sur $\mathbb{R}$.

Application : $f(x) = \frac{1}{2}x^3$

Étape 1 : $a = \frac{1}{2} > 0$
Étape 2 : $f$ est strictement croissante sur $\mathbb{R}$.

C. Fonction homographique : $f(x) = \frac{ax+b}{cx+d}$

Définition

$D_f = \mathbb{R} \setminus \left\{-\frac{d}{c}\right\}$

$\Delta = ad - bc$

Cas $\Delta > 0$ : $f$ est strictement croissante sur $]-\infty, -\frac{d}{c}[$ et $]-\frac{d}{c}, +\infty[$.

Cas $\Delta < 0$ : $f$ est strictement décroissante sur $]-\infty, -\frac{d}{c}[$ et $]-\frac{d}{c}, +\infty[$.

Vocabulaire :

  • La courbe est une hyperbole.
  • Centre de symétrie : $\Omega\left(-\frac{d}{c}, \frac{a}{c}\right)$
  • Asymptote verticale : $x = -\frac{d}{c}$
  • Asymptote horizontale : $y = \frac{a}{c}$

Application : $f(x) = \frac{2x+1}{x+1}$

Étape 1 : $\Delta = 2 \times 1 - 1 \times 1 = 1 > 0$
Étape 2 : $D_f = \mathbb{R} \setminus \{-1\}$
Étape 3 : Asymptote verticale : $x = -1$
Étape 4 : Asymptote horizontale : $y = 2$
Étape 5 : Centre de symétrie : $\Omega(-1, 2)$

Conclusion : Hyperbole avec $f$ strictement croissante sur chaque intervalle.

📈 Graphique de $f(x) = \frac{2x+1}{x+1}$

D. Fonction racine carrée : $f(x) = \sqrt{x+a}$

Cas $f(x) = \sqrt{x+a}$ :

  • $D_f = [-a, +\infty[$
  • $f$ est strictement croissante sur $D_f$.

Cas $f(x) = \sqrt{a-x}$ :

  • $D_f = ]-\infty, a]$
  • $f$ est strictement décroissante sur $D_f$.
Résumé des fonctions de référence
  • $ax^2+bx+c$ : Parabole, sommet $S\left(-\frac{b}{2a}, f(-\frac{b}{2a})\right)$.
  • $ax^3$ : Fonction impaire, monotonie selon $a$.
  • $\frac{ax+b}{cx+d}$ : Hyperbole, asymptotes $x = -\frac{d}{c}$ et $y = \frac{a}{c}$.
  • $\sqrt{x+a}$ : Croissante sur $[-a, +\infty[$.

6 Composée de deux fonctions

Définition

Soient $f$ et $g$ deux fonctions telles que $f(D_f) \subset D_g$.

$$h = g \circ f \quad \text{avec} \quad h(x) = g(f(x))$$

$D_{g \circ f} = \{ x \in D_f \mid f(x) \in D_g \}$

Exemple :

$f(x) = 2x + 3$ et $g(x) = x^2 + 1$

Étape 1 : $g \circ f(x) = g(f(x)) = (2x+3)^2 + 1$
Étape 2 : $f \circ g(x) = f(g(x)) = 2(x^2+1) + 3 = 2x^2 + 5$

Remarque : $g \circ f \neq f \circ g$ en général.

7 Monotonie de $f+c$, $c \cdot f$, $f \circ g$

Propriétés

Soit $T_f$ le taux d'accroissement de $f$ sur $I$.

$f + c$ :

$$T_{f+c} = T_f$$

$f$ et $f+c$ ont le même sens de variation sur $I$.

$c \cdot f$ :

$$T_{c \cdot f} = c \times T_f$$
  • Si $c > 0$ : $f$ et $c \cdot f$ ont le même sens de variation.
  • Si $c < 0$ : $f$ et $c \cdot f$ ont des sens opposés de variation.
Résumé
  • $f + c$ : même sens de variation.
  • $c \cdot f$ : même sens si $c > 0$, sens opposé si $c < 0$.
