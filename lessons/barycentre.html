Barycentre dans le plan

1 Barycentre de deux points pondérés

Définition

Soient $(A,a)$ et $(B,b)$ deux points pondérés du plan $(P)$, avec $A \neq B$ et $a,b \in \mathbb{R}$.

Si $a+b \neq 0$, il existe un point unique $G$ de $(P)$ tel que :

$$a\overrightarrow{GA} + b\overrightarrow{GB} = \overrightarrow{0}$$

Le point $G$ s'appelle le barycentre du système pondéré $S = \{(A,a), (B,b)\}$.

📐 Barycentre de deux points

$G$ est barycentre de $\{(A,2), (B,3)\}$ : $\overrightarrow{AG} = \frac{3}{5}\overrightarrow{AB}$

Vocabulaire
  • $a$ est le poids du point $A$.
  • $(A,a)$ est un point pondéré.
  • $S = \{(A,a), (B,b)\}$ est un système pondéré.
  • Si $a = b$ et $a \neq 0$, $G$ est l'isobarycentre de $A$ et $B$ (milieu de $[AB]$).
Démonstration
$$a\overrightarrow{GA} + b\overrightarrow{GB} = \overrightarrow{0} \iff (a+b)\overrightarrow{AG} = b\overrightarrow{AB}$$ $$\iff \overrightarrow{AG} = \frac{b}{a+b}\overrightarrow{AB}$$

Le point $G$ est unique car $A$ et $B$ sont fixes et $\frac{b}{a+b}$ est un réel fixe.

Résumé
  • Pour $a+b \neq 0$, $G$ est unique.
  • $\overrightarrow{AG} = \dfrac{b}{a+b}\overrightarrow{AB}$.
  • Si $a+b = 0$, le barycentre n'existe pas.
📝 Exercice 1

Déterminer le barycentre de $S = \{(A, 2), (B, 3)\}$.

✅ Solution

$a+b = 2+3 = 5 \neq 0$.

$\overrightarrow{AG} = \frac{3}{5}\overrightarrow{AB}$.

Donc $G$ est sur $[AB]$ tel que $AG = \frac{3}{5} AB$.

2 Propriétés du barycentre de deux points

2-1 Invariance

Théorème

Le barycentre ne change pas si on multiplie les poids par un même réel non nul $k$.

$$S = \{(A,a), (B,b)\} \iff S' = \{(A,ka), (B,kb)\}$$

2-2 Propriété caractéristique

Théorème

$G$ est barycentre de $\{(A,a), (B,b)\}$ ssi :

$$a+b \neq 0 \quad \text{et} \quad \forall M \in (P) : a\overrightarrow{MA} + b\overrightarrow{MB} = (a+b)\overrightarrow{MG}$$

📐 Propriété caractéristique

$a\overrightarrow{MA} + b\overrightarrow{MB} = (a+b)\overrightarrow{MG}$

2-3 Construction de $G$

Méthode

On divise le segment $[AB]$ en $|a+b|$ segments égaux.

  • Si $\frac{b}{a+b} > 0$ : $G$ est dans le sens $A \to B$.
  • Si $\frac{b}{a+b} < 0$ : $G$ est dans le sens opposé.
Résumé
  • Invariance : multiplier les poids par $k \neq 0$.
  • Caractéristique : $a\overrightarrow{MA} + b\overrightarrow{MB} = (a+b)\overrightarrow{MG}$.
  • Construction : $\overrightarrow{AG} = \frac{b}{a+b}\overrightarrow{AB}$.
📝 Exercice 2

Soit $G$ barycentre de $\{(A, 2), (B, -3)\}$. Déterminer $\overrightarrow{AG}$.

✅ Solution

$a+b = 2-3 = -1 \neq 0$.

$\overrightarrow{AG} = \frac{-3}{-1}\overrightarrow{AB} = 3\overrightarrow{AB}$.

$G$ est sur la droite $(AB)$ du côté de $B$.

3 Barycentre de trois points pondérés

Définition

Soient $(A,a), (B,b), (C,c)$ trois points pondérés.

Si $a+b+c \neq 0$, il existe un point unique $G$ tel que :

$$a\overrightarrow{GA} + b\overrightarrow{GB} + c\overrightarrow{GC} = \overrightarrow{0}$$

📐 Barycentre de trois points

$G$ est barycentre de $\{(A,1), (B,2), (C,3)\}$

3-1 Propriété caractéristique

Théorème
$$a\overrightarrow{MA} + b\overrightarrow{MB} + c\overrightarrow{MC} = (a+b+c)\overrightarrow{MG}$$

3-2 Associativité

Théorème

On peut remplacer deux points par leur barycentre.

Si $G_1$ est barycentre de $\{(A,a), (B,b)\}$, alors $G$ est barycentre de $\{(G_1, a+b), (C,c)\}$.

📐 Centre de gravité d'un triangle

$G$ est le centre de gravité de $ABC$ : $\overrightarrow{AG} = \frac{2}{3}\overrightarrow{AA'}$

Résumé
  • $a+b+c \neq 0$ pour l'existence.
  • Propriété caractéristique : $a\overrightarrow{MA} + b\overrightarrow{MB} + c\overrightarrow{MC} = (a+b+c)\overrightarrow{MG}$.
  • Associativité : on peut remplacer deux points par leur barycentre.
📝 Exercice 3

Soit $G$ barycentre de $\{(A, 1), (B, 2), (C, 3)\}$. Exprimer $\overrightarrow{AG}$ en fonction de $\overrightarrow{AB}$ et $\overrightarrow{AC}$.

✅ Solution

Par la propriété caractéristique avec $M=A$ :

$a+b+c = 1+2+3 = 6$.

$\overrightarrow{AG} = \frac{1}{6}(2\overrightarrow{AB} + 3\overrightarrow{AC})$.

4 Coordonnées du barycentre

Propriété

Soit $G$ barycentre de $\{(A,a), (B,b), (C,c)\}$.

Dans un repère $(O, \vec{i}, \vec{j})$, les coordonnées de $G$ sont :

$$x_G = \frac{ax_A + bx_B + cx_C}{a+b+c} \quad \text{et} \quad y_G = \frac{ay_A + by_B + cy_C}{a+b+c}$$
Résumé
  • Les coordonnées du barycentre sont les moyennes pondérées des coordonnées des points.
  • Généralisation à $n$ points.
📝 Exercice 4

Dans un repère, $A(1,1)$, $B(4,1)$, $C(-1,3)$. Déterminer les coordonnées du barycentre de $\{(A,3), (B,1), (C,1)\}$.

✅ Solution

$a+b+c = 3+1+1 = 5$.

$x_G = \frac{3(1) + 1(4) + 1(-1)}{5} = \frac{3+4-1}{5} = \frac{6}{5}$.

$y_G = \frac{3(1) + 1(1) + 1(3)}{5} = \frac{3+1+3}{5} = \frac{7}{5}$.

Donc $G\left(\frac{6}{5}, \frac{7}{5}\right)$.

5 Barycentre de quatre points

Définition

Soient $(A,a), (B,b), (C,c), (D,d)$ quatre points pondérés.

Si $a+b+c+d \neq 0$, il existe un point unique $G$ tel que :

$$a\overrightarrow{GA} + b\overrightarrow{GB} + c\overrightarrow{GC} + d\overrightarrow{GD} = \overrightarrow{0}$$

📐 Parallélogramme et son centre

$O$ est le centre du parallélogramme $ABCD$ (isobarycentre)

Coordonnées
$$x_G = \frac{ax_A + bx_B + cx_C + dx_D}{a+b+c+d} \quad \text{et} \quad y_G = \frac{ay_A + by_B + cy_C + dy_D}{a+b+c+d}$$
Remarque

Si $a = b = c = d \neq 0$, $G$ est l'isobarycentre (centre de gravité du quadrilatère).

Résumé
  • Généralisation à $n$ points.
  • Les propriétés (invariance, caractéristique, associativité) restent valables.
📝 Exercice 5

Soit $ABCD$ un parallélogramme de centre $O$. Montrer que $O$ est le barycentre de $\{(A,1), (B,1), (C,1), (D,1)\}$.

✅ Solution

Dans un parallélogramme, $O$ est le milieu de $[AC]$ et $[BD]$.

Donc $\overrightarrow{OA} + \overrightarrow{OC} = \overrightarrow{0}$ et $\overrightarrow{OB} + \overrightarrow{OD} = \overrightarrow{0}$.

Donc $\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} + \overrightarrow{OD} = \overrightarrow{0}$.

Ainsi $O$ est l'isobarycentre de $A, B, C, D$.
